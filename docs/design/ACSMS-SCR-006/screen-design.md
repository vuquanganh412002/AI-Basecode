### B. 機能詳細

- **1.0** 検索画面初期表示
- **1.1** 支店マスタ検索画面にアクセスすると、以下のように表示
  - ・中央会ユーザー：自中央会のレコードのみ編集が可能
  - ・JA本店ユーザー／JA管理支店ユーザー：自JAのレコードのみ編集が可能。
  - ※編集可能フィールドは次の項目とする。支店コード、支店名、支店カナ。（購読者情報に使われる支店コード等も同時に更新すること）
  - ・空白の検索フォーム
  - ・デフォルトの支店一覧（  ログイン中のユーザーのJA（ja_id）で支店一覧を自動フィルタリングし、表示）
- **1.2** パンくずリスト：ホーム > マスタ管理 > 支店マスタ明細検索
- **2.0** 支店検索
- **2.1** 検索条件を入力して「検索」ボタンをクリックすると、以下のように検索を実行
  - ・支店コード：部分一致検索（LIKE '%keyword%'）
  - ・支店名：部分一致検索（LIKE '%keyword%'）
  - ・管理支店：完全一致検索（kanri_shiten_id = :id）。プルダウンは ACSMS-API-COMMON-004 から取得
  - ・データ送信取扱店舗コード：部分一致検索（LIKE '%keyword%'）
  - ・金融機関支店フラグ：完全一致検索（true = 金融機関支店, false = 金融機関支店以外, 未指定 = 全選択 — 絞り込みなし）
- **2.2** データ取得成功の場合、検索条件に一致する支店一覧を表示。
- **2.3** 検索結果がない場合 → ACSMS-MSG-006-001 を表示。
- **2.4** 権限なしのアカウントの場合 → ACSMS-MSG-006-003 を表示。
- **3.0** 検索条件クリア
- **3.1** 「検索クリア」ボタンをクリックすると、全検索条件をクリア　→ACSMS-MSG-006-002メッセージを表示。
  - ・支店コード：空欄にする
  - ・支店名：空欄にする
  - ・管理支店：未選択にする
  - ・データ送信取扱店舗コード：空欄にする
  - ・金融機関支店フラグ：全選択（デフォルト）に戻す
- **3.2** デフォルトの支店一覧を表示
- **4.0** 支店編集
- **4.1** 検索結果一覧から編集したい支店を選択すると、支店編集画面に遷移。
- **4.2** IDを登録画面に渡し、既存データを取得
- **5.0** 支店削除
- **5.1** 操作列の「削除」ボタンをクリックすると、対象支店が関連テーブルに紐づいているか確認。
- **5.2** 紐づいている場合 → ACSMS-MSG-006-006 を表示。削除不可。
- **5.3** 紐づいていない場合、確認ダイアログ（ACSMS-MSG-006-005）を表示。
- **5.4** 「はい」をクリックした場合
  - ・論理削除を実行（deleted_at = NOW()）
  - ・成功メッセージ（ACSMS-MSG-006-007）を表示
  - ・検索結果一覧を再読込
- **5.5** 「いいえ」をクリックした場合 → ダイアログを閉じ、何もしない。
- **5.6** システムエラーの場合 → ACSMS-MSG-006-004 を表示。
- **6.0** ページネーション
- **6.1** 検索結果はページネーションされ
  - ・デフォルト：20件/ページ
  - ・最大：100件/ページ
- **6.2** ページナビゲーション表示：< 1 2 3 ... N >
- **7.0** 新規登録
- **7.1** 「新規登録」ボタンをクリックすると、支店登録画面へ遷移。
- **7.2** 登録画面はデフォルトで空白フォームを表示
- **8.0** ソート（並び替え）
- **8.1** ソート対象カラム:
  - ・支店コード
  - ・支店名
- **8.2** カラムヘッダーをクリックした時に実行
  - ソート順の切り替えルール:
  - ・初回クリック → 昇順（ASC）
  - ・2回目クリック → 降順（DESC）
  - ・3回目クリック → ソートなし（初期状態）に戻す
- **8.3** 現在のソート状態をカラムヘッダーにアイコンで表示
  - ・昇順: ▲アイコン
  - ・降順: ▼アイコン
  - ・ソートなし: アイコン非表示
  - 現在の検索条件を維持したままソートを実行
  - 現在の検索条件を維持したままページを切り替え
