### B. 機能詳細

- **1.0** 登録画面初期表示
- **1.1** 管理支店明細検索画面から「新規登録」ボタンをクリックすると、管理支店登録画面へ遷移する。（管理支店マスタは日農は管理者のみ操作可。中央会は自中央会のレコードのみ一部項目の編集が可能。JA本店は自JAのレコードのみ一部項目の編集が可能。JA管理支店は自JA自管理支店のレコードのみ一部項目の編集が可能。※編集可能フィールドは次の項目とする。郵便番号、住所、電話番号、FAX番号、備考。）
- **1.2** フォームは以下のデフォルト値で表示される：
  - ・紙版：未チェック
  - ・電子版：未チェック
  - ・その他の項目：空白
- **1.3** 管理支店マスタ
  - ・日農管理者のみ操作可能
- **2.0** 編集画面表示
- **2.1** 検索結果一覧の任意の行をクリックすると、管理支店登録画面（編集モード）へ遷移する。
- **2.2** システムはIDで管理支店データを取得する。
  - ・データ取得成功の場合 → フォームにデータを反映する。
  - ・データ取得失敗の場合 → ACSMS-MSG-009-005 を表示する。
  - ・権限なしのアカウントの場合 → ACSMS-MSG-009-006 を表示する。
- **2.3** 管理支店コード項目は変更不可で表示する。
- **3.0** 登録／更新
- **3.1** 「登録する」ボタンをクリックすると、入力チェックを実行する。
  - ・管理支店コード：必須、最大15文字。入力しない場合、ACSMS-MSG-009-003メッセージを表示する。
  - ・管理支店名：必須、最大100文字。入力しない場合、ACSMS-MSG-009-003メッセージを表示する。
  - ・郵便番号：最大7文字、半角数字7桁
  - ・JA：必須、選択しない場合、ACSMS-MSG-009-003メッセージを表示する。
  - ・都道府県：都道府県マスタに存在するコード。選択しない場合、ACSMS-MSG-009-003メッセージを表示する。
  - ・住所：最大200文字
  - ・電話番号：最大15文字、半角数字のみ
  - ・FAX番号：最大15文字、半角数字のみ
- **3.2** 入力チェックが不正の場合 → 該当項目の下にエラーメッセージを表示する。
- **3.3** 入力チェックが正常の場合、登録または更新を実行する。
- **3.4** 処理結果：
  - ・成功（新規登録） → ACSMS-MSG-009-001 を表示し、検索画面へ遷移する。
  - ・成功（更新） → ACSMS-MSG-009-002 を表示し、検索画面へ遷移する。
  - ・管理支店コード重複 → ACSMS-MSG-009-004 を表示する。
  - ・管理支店コードの情報が見つからない → ACSMS-MSG-009-005 を表示する。
  - ・権限なしのアカウント → ACSMS-MSG-009-006 を表示する。
  - ・システムエラー → ACSMS-MSG-009-007 を表示する。
- **4.0** 前の画面に戻る
- **4.1** 「前の画面に戻る」を選択すると、確認ポップアップ（ACSMS-MSG-009-008）が表示される。
- **4.2** フォームに入力されたデータは保存されない。
- **4.3** 「はい」ボタンをクリックする場合、管理支店マスタ明細検索画面へ遷移
- **4.4** 「いいえ」ボタンをクリックする場合、何も行わず、現在の画面を維持
