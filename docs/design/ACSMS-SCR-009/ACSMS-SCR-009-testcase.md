## システム概要

本システムは、JA向けのクラウド型読者管理システムであり、
購読者情報の管理、購読履歴の管理、口座振替データの管理などの機能を提供する。
主な機能として、購読者情報の登録・更新・検索、
購読内容の変更履歴管理、口座振替データの作成および管理、
ファイルのアップロード・ダウンロード機能、システムのお知らせ管理などを提供する。
また、ユーザーのログイン管理、ログイン履歴の記録、
ユーザー操作ログの記録などのセキュリティ・監査機能をサポートする。

- 観点ID: VP-A-01
- 種類: Normal (正常)
- 前提条件:
  - ・role: NICHINO_ADMIN
  - ・ログイン済 + MFA認証済
  - ・権限 `kanri_shiten.view` / `kanri_shiten.create` / `kanri_shiten.update` を保持

### 手順

ステップ1：
ダッシュボードを開き、サイドバーで「管理支店マスタ」項目を確認

ステップ3：

ステップ3：

HTTPステータスコード201が返却されること（`message: 登録しました。`、`m_kanri_shiten` に1行追加されること）

補足：
・NICHINO_ADMIN は管理支店マスタの全機能（参照／新規登録／更新／削除）を実行可能

- 観点ID: VP-A-01
- 種類: Abnormal (異常)
- 前提条件:
  - ・role: NICHINO_STAFF
  - ・ログイン済 + MFA認証済
  - ・権限 `kanri_shiten.view` / `kanri_shiten.create` を保持しない

### 手順

ステップ1：
ダッシュボードを開き、サイドバーで「管理支店マスタ」項目を確認

ステップ2：

ステップ3：
DevTools の Console から POST `/api/v1/kanri-shiten` を有効なリクエストボディで送信

ステップ4：

### 期待結果

ステップ1：
サイドバーに「管理支店マスタ」項目が表示されないこと（権限 `kanri_shiten.view` を持たないため）

ステップ2：
トースト `アクセス権がありません。` が表示されること、かつ `/dashboard` へ遷移すること

ステップ3：
HTTPステータスコード403が返却されること（`error_code: FORBIDDEN`、メッセージ `この画面へのアクセス権限がありません。`）

ステップ4：

  - ・将来 CHUOKAI / JA_HONTEN / JA_KANRI_SHITEN にも編集権限が付与される際の検証用シナリオ

### 手順

ステップ1：
仮にCHUOKAI（chuokai-001 所属）がログインし、他中央会管轄の管理支店レコード `kanri_shiten_id=50` へ `/kanri-shiten/50/edit` で直接アクセス

ステップ2：
DevTools の Console から GET `/api/v1/kanri-shiten/50` を実行

### 期待結果

ステップ1：
画面遷移失敗、`/dashboard` へバウンスされること、トースト `アクセス権がありません。` または NOT_FOUND が表示されること

ステップ2：
HTTPステータスコード404が返却されること（`error_code: NOT_FOUND`、メッセージ `指定された管理支店が見つかりません。`）

補足：
・データスコープ違反は存在隠蔽のため HTTP 404（NOT_FOUND）として返却される（行の存在を漏らさない）
・api.md エラー一覧では DATA_SCOPE_VIOLATION（403）と定義されているが、実装では security.md `assertJaScope` 規則に従い 404 マスキングが優先される
・現行 seed では NICHINO_ADMIN のみ操作可だが、将来非NICHINO_ADMIN にも編集権限が付与される際の検証用に本TC を残す
