### A. 機能一覧

| # | 機能 | 項目 | イベント | 説明 |
| --- | --- | --- | --- | --- |
| 1 | 画面初期表示 | — | 画面表示 | 出力条件フォームをデフォルト値で表示。プレビューエリアは空 |
| 2 | 帳票種別切替 | 帳票種別 | 変更 | 帳票種別変更時、販売店（複数選択）または管理支店（複数選択）のドロップダウンを切替表示。プレビューデータをクリア |

### B. 機能詳細


#### 1. 画面初期表示

- **1.1** 購読者名簿出力画面にアクセスすると、デフォルトで以下のように表示
  - ・出力条件フォーム
  - ・適用日：未選択
  - ・帳票種別：販売店別購読者名簿（照会用）
  - ・購読種別：未選択
  - ・販売店：未選択
  - ・管理支店：非表示（管理支店別選択時のみ活性）
  - ・プレビューエリア：空
- **1.2** 権限チェック：
  - ・日農 管理者 / 日農 担当者 → ACSMS-MSG-026-001 を表示。アクセス不可
  - ・中央会：自中央会分のみ出力可
  - ・JA本店：自JAの管理支店分のみ出力可
  - ・JA支店 → 自アカウントのkanri_shiten_idに属するデータのみ出力可
- **1.3** プルダウンリスト：
  - ・管理支店：m_kanri_shitenから取得。JA管理支店は自支店のみ表示
  - ・販売店：m_hanbaiten から取得。電子版ダミー販売店も含めて表示

#### 2. 帳票種別切替

- **2.1** 帳票種別を変更すると、
  - ・「販売店別購読者名簿」を選択 → 販売店プルダウン（複数選択可）を表示・活性化、管理支店プルダウンを非表示・非活性化
  - ・「管理支店別購読者名簿」を選択 → 管理支店プルダウン（複数選択可）を表示・活性化、販売店プルダウンを非表示・非活性化
- **2.2** 切替時、プレビューデータをクリア

#### 3. レポートプレビュー

- **3.1** 「レポートプレビュー」ボタンをクリックすると、以下をチェック
  - ・適用日：必須項目、入力しない場合：ACSMS-MSG-026-006メッセージを表示。入力した場合：「joho_henko_tekiyo_date <= 画面の適用日」で各 dokusya_id の MAX(rireki_no) を取得
  - ・帳票種別 = 販売店別の場合：販売店を選択しないと　→　ACSMS-MSG-026-002 を表示
  - ・帳票種別 = 管理支店別の場合：  管理支店を選択しないと　→ ACSMS-MSG-026-003 を表示
- **3.2** データ取得ロジック：
  - ・t_dokusya_rireki（購読者履歴テーブル）から適用日時点の最新スナップショットを取得
  - ・各dokusya_idに対しMAX(rireki_no)を取得
  - ・tetsuzuki_shurui = 1（新規）のレコードのみ。解約（tetsuzuki_shurui = 0）は除外
  - ・購読料支払区分が選択されている場合、該当区分でフィルタリング
- **3.3** 結果表示：
  - ・帳票種別 = 販売店別 → 「販売店別購読者名簿」テーブルを表示（グループ化の順序：販売店 → 管理支店 → 購読者）
  - ・帳票種別 = 管理支店別 → テーブルB表示（グループ化の順序：管理支店 → 購読者）
- **3.4** 対象データなしの場合 → ACSMS-MSG-026-004 を表示
- **3.5** システムエラーの場合 → ACSMS-MSG-026-005 を表示

#### 4. Excel出力

- **4.1** 「レポートデータExcel出力」ボタンをクリックすると、3.1と同様の条件チェックを実施
- **4.2** ・出力内容：「販売店別購読者名簿」または「管理支店別購読者名簿」テーブルの内容をExcelにそのまま出力
  - ・ファイル名：購読者名簿_{YYYY年MM月}.xlsx（適用日に基づく）
  - ・シート名：購読者名簿
  - ・データ構成：プレビューテーブルと同一（小計行・合計行を含む）
  - ・出力後の処理：S3に保存
- **4.3** 対象データなしの場合 → Excelファイルは出力しない。ACSMS-MSG-026-004 を表示
- **4.4** システムエラーの場合 → ACSMS-MSG-026-005 を表示
