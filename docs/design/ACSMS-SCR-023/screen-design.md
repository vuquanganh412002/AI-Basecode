### B. 機能詳細

- **1.0** 初期表示
- **1.1** この画面を使用するのは日農アカウントのみ
- **1.2** パンくずリスト:ホーム ＞ ファイルアップロード
- **2.0** JA追加

#### 2026-01-02 00:00:00. 「都道府県コード」ドロップダウンで都道府県コードを選択

  - ・2.1.1 ドロップダウン「都道府県コード」は初期状態で空欄（未選択）で表示される。
  - ▸都道府県コード未選択時：「都道府県」は空欄、「対象JA」セレクトボックスには全てのJA（JAコード＋JA名）が表示される。
  - ・2.1.2 API呼出：`GET /api/v1/todofuken`（共通）で都道府県一覧を取得する。
  - ▸レスポンス：`[{ todofuken_code, todofuken_name }, ...]` の一覧
  - ・2.1.3 「都道府県コード」セレクトボックスを押下した場合：
  - ▸都道府県コード＋都道府県名の一覧を表示する。
  - ・2.1.4 ユーザーが都道府県コードを1件選択した後：
  - ▸① 「都道府県」に都道府県名（todofuken_name）が自動入力される。
  - ▸② 「対象JA」セレクトボックスに該当する「JAコード + JA名」一覧が表示される。
- **2.2** セレクトボックスからJAを選択する（JAコード - JA名をm_jaから取得）
- **2.3** 「追加」ボタンを押す
  - ・API呼出：GET /api/master/ja（JA一覧をSelectBox用に取得）
  - ・JAが重複される場合→ACSMS-MSG-023-004
  - ・有効なJAの場合、JA一覧に追加（JAコード＋JA名）
- **2.4** ・複数JA選択可能。1JA＝t_file_uploadの1件レコード
・全JA選択時はja_idがNULLのレコードを1件作成（1JA=1レコードの方針、全JA向けはNULLレコード1件）
- **3.0** JA削除
- **3.1** 削除ボタンを押下すると、JAが一覧から削除され。確認ダイアログなし
- **4.0** ファイル選択
- **4.1** ドラッグアンドドロップまたはクリックしてファイル選択ダイアログ表示する。（複数選択可）
  - ・**ファイル形式チェック**（顧客レビュー 2026-05 で確定）：以下の拡張子のみ許可、その他は ACSMS-MSG-023-010 を表示してファイル一覧に追加しない。
    - Excel：.xlsx, .xls
    - PDF：.pdf
    - 画像：.jpg, .jpeg, .png
    - Word：.doc, .docx
    - PowerPoint：.pptx, .ppt
    - CSV：.csv
    - テキスト：.txt
    - 圧縮ファイル：.zip
- **4.2** ファイルのサイズチェックがあり、30MB超過の場合→ACSMS-MSG-023-002
  - ・有効なファイルの場合、ファイル一覧に追加（テキストボックスでの表示形式：「ファイル名＋サイズ」）
  - ・「削除予定日」の値は、該当トランザクションで選択されたすべてのアップロードファイルに対して一括で適用される（過去日選択不可とする）。
- **5.0** ファイル削除
- **5.1** 削除ボタンを押下すると、該当ファイルが一覧から削除され、確認ダイアログなし
- **6.0** アップロード実行
- **6.1** 「アップロード実行」ボタンを押下すると、バリデーションチェックを行い
- **6.2** ファイル未選択の場合　→　ACSMS-MSG-023-001を表示する。
  - JA未選択の場合　→　ACSMS-MSG-023-001を表示する。
  - 「削除予定日」未入力の場合　→　ACSMS-MSG-023-001を表示する。
- **6.3** 確認ダイアログ表示→OK／キャンセル →　ACSMS-MSG-023-008を表示
- **6.4** OK→POST /api/file-upload（multipart/form-data：jaIds[]＋files[]）
  - ・APIは以下の処理を**同期的に**実行し、完了後に **HTTP 202 Accepted** を返却する（メール送信完了は待たない）：
  - ▸① S3にファイルを保存（1JAにつき1ファイルを格納）
  - ▸② t_file_upload に N×M 件のレコードをINSERT（`status = 1:処理中`、`notification_status = 1:未送信`）
  - ▸③ 通知ジョブをキュー（Redis/BullMQ）に投入する。ジョブには `file_upload_id` の一覧と `ja_id` 一覧を含める。
  - ・S3定義：
  - ▸バケット名・パス構造（1JAにつき1フォルダ＋全JA向けフォルダ1つ）
  - ▸アップロードファイル名：ファイル名＋タイムスタンプ（同名ファイルは上書きで保存）
  - ▸全JA向けフォルダはすべてのJAから参照可能
  - ・ファイル保持期間：画面で指定した削除日に自動削除（NULLなら永久保存）
- **6.5** バックグラウンドワーカーによる通知メール送信（非同期）
  - ・ワーカーはキューからジョブを取り出し、**1JAごとに順次** メール送信処理を行う（AWS SES のスロットル回避＋1JA失敗が他JAへ波及しないため）。
  - ・対象アドレス：対象JAに紐付く `m_account.email` および `sub_mail_1 / sub_mail_2 / sub_mail_3`。
  - ・同一メールアドレスへの送信は1回のみとする（重複排除）。
  - ・処理開始時：`t_file_upload.notification_status = 2:送信中` に更新。
  - ・全アドレス送信成功：`notification_status = 3:完了`、`notified_at` を記録。
  - ・一部のJAで失敗：`notification_status = 4:一部失敗`、失敗JA一覧を `failed_ja_ids`（JSONB）に記録。エラーログ（t_log, log_type=3）に詳細を記録。
- **6.6** 画面表示
  - ・POSTレスポンスを受信したら、即座に成功トースト ACSMS-MSG-023-006 を表示し、フォームをクリアする。
  - ・「アップロードされたファイルリスト」を再取得し、「通知ステータス」列にバッジ（未送信／送信中／完了／一部失敗）を表示する。
  - ・APIエラー（5xxなど、S3保存／DB登録／キュー投入が失敗）の場合のみ→ACSMS-MSG-023-005 を表示。
  - ・「通知ステータス」が `4:一部失敗` の行については、運用担当者がログを確認のうえ手動で再送する（再送機能は別画面／別タイミングで対応）。
- **7.0** 「クリア」ボタン
- **7.1** 「クリア」ボタン押下時、確認ダイアログ（ACSMS-MSG-023-003）を表示
