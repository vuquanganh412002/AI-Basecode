### B. 機能詳細


#### 1. 初期表示

- **1.1** ログイン状態を確認
- **1.2** ログイン済みの場合 → メイン画面へ遷移
- **1.3** 未ログインの場合 → ログインフォームを表示
- **1.4** 初期状態: IDとパスワード空、エラーなし
- **1.5** お知らせを並行読込（ログインフォームをブロックしない）

#### 2. ユーザーID入力

- **2.1** 必須入力 → ACSMS-MSG-001-001
- **2.2** 最大20文字
- **2.3** フィールド離脱時 → 即時チェック
- **2.4** エラーフィールドは赤枠 + 下にメッセージ表示

#### 3. パスワード入力

- **3.1** 必須入力 → ACSMS-MSG-001-002
- **3.2** 8〜32文字
- **3.3** フィールド離脱時 → 即時チェック
- **3.4** マスク表示（●●●●）

#### 4. ログイン

- **4.1** 全必須フィールドをチェック
- **4.2** エラーがある場合 → 対応フィールドにエラー表示、処理停止
- **4.3** 処理中: ログインボタン無効化、待機状態を表示
- **4.4** IDとパスワードでログインリクエストを送信
- **4.5** システムがログイン情報を認証
- **4.6** 認証失敗（IDが存在しない・パスワード不一致） → ACSMS-MSG-001-005 を表示
- **4.7** 認証成功、二段階認証不要 → メイン画面（/menu）へ遷移
- **4.8** 認証成功、二段階認証必要 → 6桁の認証コードをメールで送信、Step 2へ
  - ・アカウントがロックされている場合 → ログイン不可、ACSMS-MSG-001-013 を表示
- **4.9** ログイン失敗回数を加算
  - パスワード不一致時: `login_failure_count = login_failure_count + 1` を単一トランザクションで実行
  - 加算後の値が 5 以上になった場合: 同一クエリ内で `account_lock_flg = true`、`account_lock_at = NOW()` を設定
  - 5回目（ロック発動と同時）の応答は引き続き ACSMS-MSG-001-005（INVALID_CREDENTIALS）。6回目以降は §4.8 のロック分岐に到達し ACSMS-MSG-001-013（ACCOUNT_LOCKED）を返す
  - 認証成功時: `login_failure_count = 0` にリセット
- **4.10** ロック解除条件
  - 自動解除はしない。管理者によるアカウント編集画面での手動解除のみ
  - パスワード再設定（SCR-012）はロックを解除しない

#### 5. MFAフォーム表示

- **5.1** 認証コード入力ステップへ切り替え
- **5.2** 受信先メールアドレスをマスク表示（例: t***o@example.com）
- **5.3** 5分カウントダウンを開始
- **5.4** ACSMS-MSG-001-011 を表示

#### 6. 認証コード入力

- **6.1** 必須入力 → ACSMS-MSG-001-003
- **6.2** 6桁必須 → ACSMS-MSG-001-004
- **6.3** フィールド離脱時 → 即時チェック
- **6.4** 数字（0-9）のみ入力可能

#### 7. 認証コード検証

- **7.1** 入力した認証コードをチェック
- **7.2** エラーがある場合 → フィールドにエラー表示、処理停止
- **7.3** 処理中: 認証ボタン無効化
- **7.4** 認証コード検証リクエストをシステムに送信
- **7.5** コードの有効期限が切れている、または無効 → ACSMS-MSG-001-007 を表示
- **7.6** 5回以上間違えた場合 → 現在のコードを無効化、ACSMS-MSG-001-008 を表示、ログイン画面に戻る（再ログインして新しいコードを取得する必要あり）
- **7.7** コード不正 → ACSMS-MSG-001-006 を表示、再入力を許可
- **7.8** コード正しい → ログイン成功、メイン画面へ遷移

#### 8. 認証コード再送

- **8.1** 「コードを再送する」リンクを押下
- **8.2** 前回送信から60秒未経過 → 再送不可、リンク上に残り秒数を表示
- **8.3** 送信回数が3回（初回含む）を超えた場合 → ACSMS-MSG-001-012 を表示、ログイン画面に戻され
- **8.4** 旧コードを無効化
- **8.5** 新しい6桁コードを発行
- **8.6** 入力失敗回数は0にリセット（新しいコードで再カウント）
- **8.7** カウントダウンを5分にリセット
- **8.8** 再送リンクの60秒クールダウンを開始
- **8.9** 新しいコードをメール送信
- **8.10** ACSMS-MSG-001-011 を表示
- **8.11** システムエラー時 → ACSMS-MSG-001-010 を表示

#### 9. ログイン成功

- **9.1** ログイン情報をブラウザに保存（HttpOnly Cookie（Secure + SameSite=Strict）に保存され、24時間有効です。）
- **9.2** ユーザー情報を保存
- **9.3** カウントダウンを停止（MFAの場合）
- **9.4** メイン画面（/menu）へ遷移

#### 10. ログインエラー

- **10.1** 認証失敗（ID不存在 / パスワード不一致） → ACSMS-MSG-001-005 を表示
- **10.2** アカウントロック状態 → ACSMS-MSG-001-013 を表示（リトライ不可、管理者へ連絡）
- **10.3** システムエラー → ACSMS-MSG-001-010 を表示
- **10.4** リトライを許可（ロック時を除く）

#### 11. MFAエラー

- **11.1** コード不正 → ACSMS-MSG-001-006 を表示、再入力を許可
- **11.2** コード期限切れ → ACSMS-MSG-001-007 を表示、Step 1に戻る
- **11.3** 5回以上間違い → ACSMS-MSG-001-008 を表示、Step 1に戻る
- **11.4** システムエラー → ACSMS-MSG-001-010 を表示

#### 12. ログインに戻る

- **12.1** 戻るリンクをクリック
- **12.2** 二段階認証の状態をリセット
- **12.3** カウントダウンを停止
- **12.4** ログインフォームStep 1を再表示

#### 13. カウントダウン期限切れ

- **13.1** 毎秒カウントダウン
- **13.2** 0の場合 → 期限切れを表示
- **13.3** 認証ボタンを無効化
- **13.4** 戻るのクリックのみ許可

#### 14. お知らせ読込

- **14.1** 公開お知らせ一覧を取得（ログイン不要）
- **14.2** 条件: ログイン画面向け（公開場所=1）、種別=1/2/3（4:締め切り時間は除外）、公開中、有効期限内、最大20件
- **14.3** 成功 → 一覧を表示
- **14.4** エラー → お知らせエリアを非表示、ログインに影響なし

#### 15. お知らせ表示

- **15.1** お知らせあり → お知らせエリアを表示
- **15.2** お知らせなし → エリアを非表示
- **15.3** 各項目の表示: 日付（YYYY.MM.DD）+ タイトル
- **15.4** 更新日時の降順で並び替え（更新日時が無い場合は作成日時）
- **15.5** 表示は5件まで。5件を超える場合はお知らせエリア内にスクロールバーを表示し、全件を保持する
