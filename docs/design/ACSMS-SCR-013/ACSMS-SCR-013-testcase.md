## システム概要

本システムは、JA向けのクラウド型読者管理システムであり、
購読者情報の管理、購読履歴の管理、口座振替データの管理などの機能を提供する。
主な機能として、購読者情報の登録・更新・検索、
購読内容の変更履歴管理、口座振替データの作成および管理、
ファイルのアップロード・ダウンロード機能、システムのお知らせ管理などを提供する。
また、ユーザーのログイン管理、ログイン履歴の記録、
ユーザー操作ログの記録などのセキュリティ・監査機能をサポートする。

## ACSMS-TC-013-001 — 画面アクセス禁止（NICHINO_ADMIN）

- 観点ID: VP-A-01
- 種類: Abnormal (異常)
- 前提条件:
  - ・role: NICHINO_ADMIN
  - ・ログイン済 + MFA認証済
  - ・権限「dokusya.view」を持たない（seeder.md §3 マトリクス No.2 ×）

### 手順

ステップ1：
ダッシュボードを開き、サイドバーおよびメニューに「購読者明細検索」項目が表示されないことを確認

ステップ2：
ブラウザのアドレスバーに購読者履歴情報画面のURL（`/dokusya/1/rireki`）を入力し、直接アクセス

ステップ3：
DevTools の Network タブで GET `/api/v1/dokusya/1/rireki` を直接呼び出し

### 期待結果

ステップ1：
メニューが表示されないこと（`dokusya.view` 権限を持たないため）

ステップ2：
トースト `アクセス権がありません。` が表示されること、かつ `/dashboard` へ遷移すること
