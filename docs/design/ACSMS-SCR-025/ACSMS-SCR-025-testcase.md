## システム概要

本システムは、JA向けのクラウド型購読者管理システムであり、
購読者情報の管理、購読履歴の管理、口座振替データの管理などの機能を提供する。
主な機能として、購読者情報の登録・更新・検索、
購読内容の変更履歴管理、口座振替データの作成および管理、
ファイルのアップロード・ダウンロード機能、システムのお知らせ管理などを提供する。
また、ユーザーのログイン管理、ログイン履歴の記録、
ユーザー操作ログの記録などのセキュリティ・監査機能をサポートする。

## ACSMS-TC-025-001 — NICHINO_ADMIN によるアカウントマスタ登録画面アクセス（正常）

- 観点ID: VP-A-01
- 種類: Normal (正常)
- 前提条件:
  - ・role: NICHINO_ADMIN
  - ・ログイン済 + MFA認証済
  - ・`account.view` + `account.create` + `account.update` 権限保有

### 手順

ステップ1：
ダッシュボードを開き、サイドバーで「管理者機能」配下「アカウントマスタ」項目を確認

ステップ2：

ステップ3：
URL `/accounts/create` に直接アクセス

ステップ4：
DB 確認: `SELECT * FROM t_log WHERE result_status = 1 AND gamen_name LIKE '%アカウントマスタ%' ORDER BY log_datetime DESC LIMIT 1`

### 期待結果

ステップ1：
サイドバーに「アカウントマスタ」項目が表示されること（NICHINO_ADMIN は `account.view` を保有）

ステップ2：
アカウントマスタ登録画面が表示されること（タイトル `アカウントマスタ登録` 、フォーム全項目が活性化していること）

ステップ3：
画面が正常に描画されること、認可エラーが発生しないこと

ステップ4：
画面アクセスログ 1 行以上が記録されること、`account_id` がテストアカウントと一致すること

補足：
・NICHINO_ADMIN はアカウントマスタを操作できる唯一のロールであること
