- **概要**: 購読者Excelデータ取込画面

### A. 機能一覧

| # | 機能 | 項目 | イベント | 説明 |

### B. 機能詳細

- **1.0** 初期表示
- **1.1** 画面がデフォルト状態で表示され、取込列パネルは展開された状態で、全てのチェックボックスが選択済みの状態にある。
  - 中央会：自中央会のみ選択可（管轄JAの読者は見れない）
  - JA本店：自JAのみ選択可。
  - JA管理支店：自管理支店のみ選択可。
  - 日農アカウント：アクセス不可
- **2.0** Excelファイル選択
- **2.1** 「Excelファイル選択」ボタンをクリック → .xlsx/.xlsフィルター付きダイアログが表示される。
- **2.2** ファイル選択後の処理:
  - ・ 先頭シートを取得
  - ・ 1行目 → ファイル内の列ヘッダー一覧
  - ・ 残りの行 → 取込データ
  - ・ 取り込み失敗の場合 → ACSMS-MSG-016-001 を表示する。
  - ・ 取り込み成功 → プレビューエリアを更新する（機能6参照）
- **3.0** 取込モード選択
- **3.1** ラジオボタンから選択する: 新規登録 / 更新（v1.4。全項目更新は廃止）
- **3.2** デフォルト値: 新規登録
- **4.0** テンプレートダウンロード
- **4.1** システムがExcelファイルを生成し、シート名: 「購読者」、1行目に49列を以下の順序通りに設定する。
  - ・ID 、購読種別、手続種類、管理支店、支店、組合員コード、住所、購読者苗字（漢字）、購読者名前（漢字）、購読者苗字（かな）、購読者名前（かな）
  - ・ 購読部数、新聞単価、メールアドレス、メールマガジン、生年（西暦）、性別、郵便番号、都道府県、市町村郡、丁目番地 、マンション・アパート名、連絡先１、連絡先２、郵便番号(配達先)、都道府県(配達先)市町村郡(配達先)、丁目番地(配達先)、ﾏﾝｼｮﾝ・ｱﾊﾟｰﾄ名(配達先)、連絡先１(配達先)、連絡先２(配達先)
  - ・ 配達先苗字（漢字）、配達先名前（漢字）、配達先苗字（かな）、配達先名前（かな）、販売店コード、郵送区分、支払方法、購読料支払サイクル（月数）、引落口座貯金種目、引落口座支店コード、引落口座支店名、引落口座番号、引落口座名義、読者層分類、農業者分類、購読開始日、購読中止日、備考、読者情報変更適用日
  - ・数字コードと文言の両方での取込みに対応する（例: 引落口座貯金種目は「1」「2」のほか「普通」「当座」も可、性別は「男性」「女性」「回答しない」も可
- **4.2** ファイル名 ＝ 購読者Excelデータ取込_テンプレート.xlsx でダウンロード
- **5.0** 取込列パネルの折りたたみ・展開
- **5.1** パネルが展開状態のとき、クリックすると折りたたまれる。
- **5.2** パネルが折りたたみ状態のとき、クリックすると展開される。
- **6.0** 取込列チェックボックス操作
- **6.1** チェックボックスにチェック入れ／チェック解除により、各チェックボックスの状態を更新。取込モード＝新規登録の場合のみ必須列は常にチェック済みで選択不可。更新モードは既定で全列未チェック（キー列のみチェック＋選択不可）で、必要な列をユーザーが選ぶ。全列更新は「すべて選択」でチェックする（v1.4）。
- **6.2** 取込データプレビューを再描画する（チェック済み列のみ表示）
- **7.0** 取込データプレビュー表示
- **7.1** 表示条件: ファイル選択済み かつ データが1行以上存在する
- **7.2** 列マッピング: 完全一致
- **7.3** 非表示条件: ファイル未選択、またはファイルが空の場合
- **8.0** 取込処理実行
- **8.1** クライアント側でバリデーションチェックを行う（順序通り）:
  - ・ ファイル未選択 → バリデーションエラー、処理停止、ACSMS-MSG-016-001を表示する。
  - ・購読種別：電子版かつ支払方法がクレジットカードの場合は取込不可とする。→ ACSMS-MSG-016-005 を表示する（エラー理由：電子版かつクレカ決済取込不可のため）
  - ・購読部数のチェック処理を行う（新規登録: 購読部数 > 0 であること、解約: 購読部数 = 0 であること）
  - ・データ行数 > 30000件の場合 → バリデーションエラー、処理停止、ACSMS-MSG-016-006を表示する。
- **8.2** 確認ダイアログ（ACSMS-MSG-016-002）
  - ・ 「いいえ」→ ダイアログを閉じ、処理しない
  - ・ 「はい」→ データ変換後サーバーへ送信する。
- **8.3** データ変換・送信：取込み済みのデータを使用し（再取込みなし）、チェック有の列のみを対象とし、レコードリストに変換する（最大30000行）
- **8.4** 結果処理:
  - ・ 取込み成功の場合（0件エラー）→ 取込件数を表示 → ACSMS-MSG-016-004 を表示する（取込時、配達先フィールドの入力有無からアプリ側で自動判定）
  - ・ エラー発生の場合：全件ロールバック、ACSMS-MSG-016-005を表示し、エラー表示件数は最大10件に上限とする。
  - ・一括中止の場合、組合員コードをキーにして手続種別を解約し、購読中止日を記載して更新する。
  - ・Excelファイルから取り込んだデータ件数に応じて、取り込みモード（新規登録／全項目更新／入力箇所のみ更新）に基づき、同件数分のレコードを t_dokusya_rireki テーブルに追加する。
  - ・ システムエラー (HTTP 500) → ACSMS-MSG-016-003 を表示
