### B. 機能詳細

- **1.0** 初期表示
- **1.1** 画面がデフォルト状態で表示され、取込列パネルは展開された状態で、全てのチェックボックスが選択済みの状態にある。
  - 中央会：自中央会のみ選択可（管轄JAの読者は見れない）
  - JA本店：自JAのみ選択可。
  - JA管理支店：自管理支店のみ選択可。
  - 日農アカウント：アクセス不可
- **2.0** Excelファイル選択
- **2.1** 「Excelファイル選択」ボタンをクリック → .xlsx/.xlsフィルター付きダイアログが表示される。
- **2.2** ファイル選択後の処理:
  - ・ 先頭シートを取得
  - ・ 1行目 → ファイル内の列ヘッダー一覧
  - ・ 残りの行 → 取込データ
  - ・ 取り込み失敗の場合 → ACSMS-MSG-016-001 を表示する。
  - ・ 取り込み成功 → プレビューエリアを更新する（機能6参照）
- **3.0** 取込モード選択
- **3.1** ラジオボタンから選択する: 新規登録 / 更新（v1.4。全項目更新は廃止）
- **3.2** デフォルト値: 新規登録
- **3.3** 購読種別選択（v1.5・顧客要件 2026-07）: ラジオボタンから選択する: 紙版(1) / 電子版(2)。デフォルト値: 紙版。選択した種別を全取込行へ一律適用する（Excel の列ではない＝単一ソース）。3:併読はラジオに出さず取込不可。
- **4.0** テンプレートダウンロード
- **4.1** システムがExcelファイルを生成し、シート名: 「購読者」、1行目に48列を以下の順序通りに設定する（v1.5：購読種別は画面ラジオの単一ソースのため列に含めない）。
  - ・ID 、手続種類、管理支店、支店、組合員コード、住所、購読者苗字（漢字）、購読者名前（漢字）、購読者苗字（かな）、購読者名前（かな）
  - ・ 購読部数、新聞単価、メールアドレス、メールマガジン、生年（西暦）、性別、郵便番号、都道府県、市町村郡、丁目番地 、マンション・アパート名、連絡先１、連絡先２、郵便番号(配達先)、都道府県(配達先)市町村郡(配達先)、丁目番地(配達先)、ﾏﾝｼｮﾝ・ｱﾊﾟｰﾄ名(配達先)、連絡先１(配達先)、連絡先２(配達先)
  - ・ 配達先苗字（漢字）、配達先名前（漢字）、配達先苗字（かな）、配達先名前（かな）、販売店コード、郵送区分、支払方法、購読料支払サイクル（月数）、引落口座貯金種目、引落口座支店コード、引落口座支店名、引落口座番号、引落口座名義、読者層分類、農業者分類、購読開始日、購読中止日、備考、読者情報変更適用日
  - ・数字コードと文言の両方での取込みに対応する（例: 引落口座貯金種目は「1」「2」のほか「普通」「当座」も可、性別は「男性」「女性」「回答しない」も可
- **4.2** ファイル名 ＝ 購読者Excelデータ取込_テンプレート.xlsx でダウンロード
- **5.0** 取込列パネルの折りたたみ・展開
- **5.1** パネルが展開状態のとき、クリックすると折りたたまれる。
- **5.2** パネルが折りたたみ状態のとき、クリックすると展開される。
- **6.0** 取込列チェックボックス操作
- **6.1** チェックボックスにチェック入れ／チェック解除により、各チェックボックスの状態を更新。取込モード＝新規登録の場合のみ必須列は常にチェック済みで選択不可。更新モードは既定で全列未チェック（キー列のみチェック＋選択不可）で、必要な列をユーザーが選ぶ。全列更新は「すべて選択」でチェックする（v1.4）。
- **6.2** 取込データプレビューを再描画する（チェック済み列のみ表示）
- **7.0** 取込データプレビュー表示
- **7.1** 表示条件: ファイル選択済み かつ データが1行以上存在する
- **7.2** 列マッピング: 完全一致
- **7.3** 非表示条件: ファイル未選択、またはファイルが空の場合
- **8.0** 取込処理実行
- **8.1** クライアント側でバリデーションチェックを行う（順序通り）:
  - ・ ファイル未選択 → バリデーションエラー、処理停止、ACSMS-MSG-016-001を表示する。
  - ・購読種別：**画面上部の 購読種別 ラジオ（紙版/電子版）で一律指定する単一ソース（v1.5）**。1:紙版 / 2:電子版 のみ取込可。3:併読はラジオに出さず取込不可（第3システム同期のため読取専用）。電子版かつ支払方法がクレジットカードの場合も取込不可とする。→ ACSMS-MSG-016-005 を表示する（エラー理由：電子版かつクレカ決済取込不可のため）。更新モードでは、更新対象の既存購読者の購読種別が選択したラジオと異なる行を取込不可とする（エラー：選択した購読種別と異なる購読者が含まれています。）。
  - ・購読部数のチェック処理を行う（新規登録: 購読部数 > 0 であること、解約: 購読部数 = 0 であること）。**電子版は購読部数=1固定**（顧客要件 2026-07 改訂・UI/一括置換と統一）。
  - ・**読者情報変更適用日（UPDATE）の日付ルールは購読種別依存**（顧客要件 2026-07 改訂・UI編集/一括置換と統一）：過去日不可。電子版=**当日のみ**。紙版=**当日変更 + 予約変更（未来日）可**だが、帳票影響項目（部数・販売店・購読者住所・配達先住所）を当日変更した場合は予約変更（未来日）を要求する。
  - ・データ行数 > 30000件の場合 → バリデーションエラー、処理停止、ACSMS-MSG-016-006を表示する。
  - ・**適用日／中止日は画面の入力欄で指定する**（→ 機能定義 9）。未入力・同時入力は処理停止。
- **8.2** 確認ダイアログ（ACSMS-MSG-016-002）
  - ・ 「いいえ」→ ダイアログを閉じ、処理しない
  - ・ 「はい」→ データ変換後サーバーへ送信する。
- **8.3** データ変換・送信：取込み済みのデータを使用し（再取込みなし）、チェック有の列のみを対象とし、レコードリストに変換する（最大30000行）
- **8.4** 結果処理:
  - ・ 取込み成功の場合（0件エラー）→ 取込件数を表示 → ACSMS-MSG-016-004 を表示する（取込時、配達先フィールドの入力有無からアプリ側で自動判定）
  - ・ エラー発生の場合：全件ロールバック、ACSMS-MSG-016-005を表示し、エラー表示件数は最大10件に上限とする。
  - ・Excelファイルから取り込んだデータ件数に応じて、取り込みモード（新規登録／全項目更新／入力箇所のみ更新）に基づき、同件数分のレコードを t_dokusya_rireki テーブルに追加する。
  - ・ システムエラー (HTTP 500) → ACSMS-MSG-016-003 を表示

#### 9. 読者情報変更適用日 / 購読中止日（顧客要件 2026-08）

適用日と中止日は **Excel の列ではなく画面の入力欄**で指定する。1ファイルに1つで、
行ごとに別の値は持てない。列に残すと画面と Excel のどちらが勝つのか説明できないため、
テンプレートからは撤去した（48 → 46 列）。

- **9.1** 新規登録モードでは両方とも入力不可（新規登録に「変更適用日」「中止日」の概念が無い）。
  モードを新規登録へ戻したときは入力値をクリアする。
- **9.2** 更新モードでは **どちらか一方のみ**入力できる。片方を入力すると他方はクリア＋入力不可。
  - ・両方指定 → ACSMS-MSG-016-007
  - ・両方未入力 → ACSMS-MSG-016-008（電子版は 9.3 のとおり適用日が当日固定のため対象外）
  - ・新規登録での指定 → ACSMS-MSG-016-009 / ACSMS-MSG-016-010
- **9.3** 電子版は適用日=**当日固定**。入力欄には当日を表示したまま入力不可とし、ACSMS-MSG-016-012 を併記する（何が適用されるのかを見せるため空欄にはしない）。
- **9.4** 紙版で適用日に**当日**を指定した場合、帳票影響項目（購読部数・販売店コード・購読者住所4項目・配達先住所5項目 の計12列）は取込列として**選択できない**。ACSMS-MSG-016-013 を表示する。未来日（＝予約変更）に変更すると選択可能に戻る。
- **9.5** **購読中止日を入力した取込は「一括中止」**として扱う（ACSMS-MSG-016-014）。
  - ・取込列はキー列（ID）だけに縮退し、他の列は選択も更新もしない。
  - ・対象ごとに解約予約（購読部数=0・購読中止日あり・解約フラグ=false）の履歴を1件追加する。中止日は予約時点で購読者テーブルにも反映し一覧・詳細へ即時表示する。**解約の確定（手続種類=解約）は到来日バッチ**が行う。
  - ・**電子版**は同一処理内で電子版システムへ解約連携する。1件でも失敗した場合は全件ロールバックし、既に連携済みの分へ打ち消しを送る。打ち消しにも失敗した分は会員IDをエラーログに記録する（運用で手動対応が必要な対象）。
  - ・**紙版**は外部連携を行わない。
  - ・電子版の一括中止は **1回あたり500件まで**（ACSMS-MSG-016-011）。紙版は従来どおり30000件まで。
  - ・取込画面に「一括取消（解約予約の取り消し）」は無い。予約の変更・取消は購読者明細検索画面（SCR-014）の購読中止から1件ずつ行う。
