## システム概要

本システムは、JA向けのクラウド型読者管理システムであり、購読者情報の管理、購読履歴の管理、口座振替データの管理などの機能を提供する。本画面は、Excelファイルから購読者データを一括取込（新規登録／全項目更新／入力箇所のみ更新）する機能を提供する。

## 資料目的

「購読者Excelデータ取込画面（ACSMS-SCR-016）」において、システム上で新規作成されるテスト仕様書の詳細を記述した資料です。

- 各機能が設計仕様どおりに動作することを確認すること
- アクセス権限制御およびデータスコープが正しく適用されることを確認すること
- 業務ロジックおよび入力値検証が正しく機能することを確認すること
- 異常系・共通エラーハンドリングが適切に処理されることを確認すること

## ACSMS-TC-016-003 — CHUOKAI による購読者Excelデータ取込 — 自中央会管轄内のみ取込可

- 観点ID: VP-A-02
- 種類: Normal (正常)
- 前提条件:
  - ・role: CHUOKAI（chuokai-001 所属）
  - ・管轄JA: ja-001, ja-002（chuokai-001 配下）
  - ・他中央会管轄JA: ja-099（chuokai-002 配下）
  - ・ログイン済 + MFA認証済

### 手順

ステップ1：
URL `/dokusya/import` にアクセス、ja-001 のテンプレートExcelをアップロード、取込モード「新規登録」を選択

ステップ2：
取込開始ボタン押下 → 確認ダイアログ「実行」

ステップ3：
DevTools で POST `/api/v1/dokusya/import` に ja-099 配下の `kanri_shiten_id` を含むリクエストパラメータを送信

### 期待結果

ステップ1：
購読者Excelデータ取込画面が表示されること、プレビューが正常表示されること

ステップ2：
HTTPステータスコード200が返却されること、ja-001 配下にデータが新規登録されること、`t_dokusya.ja_id = 1` で保存されること

ステップ3：
ja-099 のデータがCHUOKAI セッションの `ja_id` ではないため、HTTPステータスコード403が返却されること（`error_code: DATA_SCOPE_VIOLATION`、メッセージ `このデータへのアクセス権限がありません。`）

補足：
・Layer 2 DataScopeにより管轄外JAへの取込は拒否されること
・サーバー側ではセッションの `ja_id` で一律絞り込むため、リクエスト中の他JA `ja_id` 指定は無視またはエラーとなること
