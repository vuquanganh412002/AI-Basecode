## システム概要

本システムは、JA向けのクラウド型読者管理システムであり、
購読者情報の管理、購読履歴の管理、口座振替データの管理などの機能を提供する。
主な機能として、購読者情報の登録・更新・検索、
購読内容の変更履歴管理、口座振替データの作成および管理、
ファイルのアップロード・ダウンロード機能、システムのお知らせ管理などを提供する。
また、ユーザーのログイン管理、ログイン履歴の記録、
ユーザー操作ログの記録などのセキュリティ・監査機能をサポートする。

- **観点ID**: VP-A-01
- **種類**: Normal (正常)
- **前提条件**:
  - ・role: CHUOKAI（chuokai-001 所属）
  - ・管轄JA: ja-001, ja-002 (chuokai-001 配下)
  - ・管轄外JA: ja-101 (chuokai-002 配下)

### 手順

ステップ1：

ステップ4：
管轄外JA (ja-101) の単価詳細URL `/tanka/{id}/edit` を直接入力

ステップ5：
DevTools で PATCH `/api/v1/tanka/{管轄外id}` を直接呼び出し

### 期待結果

ステップ1：
表示される（`tanka.view` 権限あり）

ステップ2：
正常表示。一覧には ja-001 / ja-002 配下の単価のみ表示

ステップ3：
`/tanka/create` フォーム画面が開く

ステップ4：
404 NotFound（DataScope により存在しないとして扱う）

ステップ5：
HTTP 404, `error_code: NOT_FOUND`（403 ではない — out-of-scope は存在隠蔽）

補足：
・管轄内JAの単価は閲覧/作成/編集/削除可能
・管轄外JAの単価への直接アクセスは 404 で遮断

・出スコープアクセスは存在隠蔽のため HTTP 404（NOT_FOUND）として返却される。api.md エラー一覧では DATA_SCOPE_VIOLATION（403）と定義されているが、実装では security.md `assertJaScope` 規則に従い 404 マスキングが優先される。
