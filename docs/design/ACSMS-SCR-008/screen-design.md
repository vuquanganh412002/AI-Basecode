### B. 機能詳細

- **1.0** 検索画面初期表示
- **1.1** 管理支店検索画面にアクセスすると、以下を表示する。
  - ・空白の検索フォーム
  - ・デフォルトの管理支店一覧（  ログイン中のユーザーのJA（ja_id）で管理支店一覧を自動フィルタリングし、表示）
- **1.2** パンくずリスト：ホーム > 管理支店マスタ明細検索
- **1.3** 管理支店マスタ
  - ・日農は管理者のみ操作可。
  - ・中央会は自中央会のレコードのみ一部項目の編集が可能。
  - ・JA本店は自JAのレコードのみ一部項目の編集が可能。
  - ・JA管理支店は自JA自管理支店のレコードのみ一部項目の編集が可能。
  - ※編集可能フィールドは次の項目とする。郵便番号、住所、電話番号、FAX番号、備考。
- **2.0** 管理支店検索
- **2.1** 検索条件を入力して「検索」ボタンをクリックすると、以下のように検索を実行する。
  - ・管理支店コード：部分一致検索（LIKE '%keyword%'）
  - ・管理支店名：部分一致検索（LIKE '%keyword%'）
  - ・電話番号：部分一致検索（LIKE '%keyword%'）
  - ・都道府県 ：完全一致検索（= 'todofuken_code'）※プルダウン選択
  - ・FAX番号：部分一致検索（LIKE '%keyword%'）
- **2.2** 検索条件に一致する管理支店一覧を表示する。
- **2.3** 検索結果は常に最新順で表示される。
- **2.4** 検索結果がない場合 → ACSMS-MSG-008-001 を表示する。
- **2.5** 権限なしのアカウントの場合 → ACSMS-MSG-008-002 を表示する。
- **2.6** システムエラーの場合 → ACSMS-MSG-008-003 を表示する。
- **3.0** 検索条件クリア
- **3.1** 「検索クリア」ボタンをクリックすると、全検索条件をクリアする。
  - ・管理支店コード：空欄にする
  - ・管理支店名：空欄にする
  - ・電話番号：空欄にする
  - ・FAX番号：空欄にする
- **3.2** デフォルトの管理支店一覧を表示する。
- **4.0** 新規登録
- **4.1** 「新規登録」ボタンをクリックすると、管理支店マスタ登録画面へ遷移する。
- **4.2** 登録画面はデフォルト値で空白フォームを表示する。
- **5.0** 管理支店編集
- **5.1** 検索結果一覧から編集したい管理支店を選択すると、管理支店編集画面へ遷移する。
- **5.2** 管理支店IDを登録画面に渡し、既存データを取得する。
- **6.0** ページネーション
- **6.1** 検索結果はページネーションされる。
  - ・デフォルト：20件/ページ
  - ・最大：100件/ページ
- **6.2** ページナビゲーション表示：< 1 2 3 ... N >
- **7.0** 管理支店削除
- **7.1** 操作列の「削除」ボタンをクリックすると、対象管理支店が関連テーブルに紐づいているか確認する。
- **7.2** 紐づいている場合 → ACSMS-MSG-008-004 を表示し、削除不可とする。
- **7.3** 紐づいていない場合、確認ダイアログ（ACSMS-MSG-008-005）を表示する。
  - 「はい」をクリックした場合：
  - ・システムは論理削除を実行（deleted_at = NOW()）
  - ・成功メッセージ（ACSMS-MSG-008-006）を表示する。
  - ・検索結果一覧を再度読み込む。
- **7.4** 「いいえ」をクリックした場合 → ダイアログを閉じ、何もしない。
- **7.5** システムエラーの場合 → ACSMS-MSG-008-003 を表示する。
- **8.0** ソート（並び替え）
- **8.1** ソート対象カラム:
  - ・管理支店コード
  - ・管理支店名
  - ・都道府県
- **8.2** カラムヘッダーをクリックした時に実行する。
  - ソート順の切り替えルール:
  - ・初回クリック → 昇順（ASC）
  - ・2回目クリック → 降順（DESC）
  - ・3回目クリック → ソートなし（初期状態）に戻す
- **8.3** 現在のソート状態をカラムヘッダーにアイコンで表示する。
  - ・昇順: ▲アイコン
  - ・降順: ▼アイコン
  - ・ソートなし: アイコン非表示
  - 現在の検索条件を維持したままソートを実行する。
