### A. 機能一覧

| # | 機能 | 項目 | イベント | 説明 |
| --- | --- | --- | --- | --- |
| 1.0 | 画面初期表示 | — | 画面表示 | 出力条件フォームをデフォルト値で表示。プレビューエリアは空 |
| 2.0 | レポートプレビュー | レポートプレビュー | クリック | 条件をチェックし、データを取得して通知テーブルに表示 |
| 3.0 | 電子帳票作成 | 電子帳票作成 | クリック | 条件をチェックし、通知ファイル（PDF）を生成 |

### B. 機能詳細


#### 1. 画面初期表示

- **1.1** 増減通知（日本農業新聞）出力画面にアクセスすると、デフォルトで以下のように表示され
  - ・出力条件フォーム
  - ・適用日：未選択
  - ・管理支店：未選択
  - ・プレビューエリア：空
- **1.2** 権限チェック：
  - ・日農 管理者 / 日農 担当者 → ACSMS-MSG-029-001 を表示。アクセス不可
  - ・中央会：自中央会分のみ出力可
  - ・JA本店：自JAの管理支店分のみ出力可
  - ・JA管理支店 → 自アカウントのkanri_shiten_idに属するデータのみ出力可
- **1.3** プルダウンリスト：
  - ・管理支店：m_kanri_shitenから取得。JA管理支店は自支店のみ表示

#### 2. レポートプレビュー

- **2.1** データ取得ロジック：
  - ・t_dokusya_rireki テーブルからレコードを抽出
  - ・適用日：必須項目、入力しない場合：ACSMS-MSG-029-004メッセージを表示。データの変更適用日 = 画面条件の適用日のものを抽出
  - ・管理支店が選択されている場合（全てでない場合）、該当管理支店でフィルタリング。電子版のダミー販売店は表示しない
  - ・JA管理支店権限の場合 → kanri_shiten_id の条件を追加
- **2.2** グループ化と並び順：
  - ・管理支店単位でグループ化 → 各管理支店に1枚の帳票
  - ・電子版ダミー販売店及び「現在部数 = 0 AND 新部数 = 0」のレコードは表示されない
- **2.3** 結果表示：
  - ・通知テーブルをプレビューエリアに表示
  - ・テーブルは次のカラムで構成：委託 / 販売店コード / 販売店名 / 現在部数 / 増部数 / 減部数 / 新部数。販売店コードの昇順で並べ替え
  - ・免税の販売店は販売店名の前に「（免）」を付記（インボイス番号があるかなしかで判断）
  - ・増部数・減部数がともに0のレコードも表示
  - ・テーブル末尾に合計行（合計行）を表示
  - ・委託区分が「日農への委託」の販売店の場合：「委託」と表示
  - ・委託区分が「振込」、「その他」の場合は空欄とする
  - ・前回出力した部分との差があった場所に◆をつける
  - ・帳票ヘッダー：組合名は管理支店コード：JAマスタのJA名称+管理支店名を表示
  - 管理支店コードは10桁で3-4-3でハイフンで区切る
  - ページ数を表示：Page: 現在ページ/全体数
- **2.4** 対象データなしの場合 → ACSMS-MSG-029-002 を表示
- **2.5** システムエラーの場合 → ACSMS-MSG-029-003 を表示

#### 3. 電子帳票作成

- **3.1** 「電子帳票作成」ボタンをクリックすると、2.1と同様のデータ取得を実施
  - ・「電子帳票作成」ボタンを押下する時、確認ダイアログ（ACSMS-MSG-029-005）を表示
  - ・「はい」ボタンを押下する場合、帳票作成処理を実行
  - ・「いいえ」ボタンを押下する場合、処理を中止
- **3.2** データが有効な場合、帳票ファイルを生成：（ファイルのテンプレートはまだ共有していただいないため、ご共有いただいた後に更新があれば追記させていただく）
  - ・出力形式：PDF
  - ・出力後の処理：S3に保存 ＋ 日農担当者へメール自動通知
  - ・ファイル命名規則：「増減通知_管理支店コード_適用日（YYYYMMDD）.pdf」
  - ・保存先パス：「s3://{bucket}/reports/zogen_notification/{YYYY}/{MM}/{DD}/」
  - ・ファイルダウンロード時の表示名：S3に保存されたファイル名をそのまま使用
- **3.3** 対象データなしの場合 → ファイルは出力しない。ACSMS-MSG-029-002 を表示
- **3.4** システムエラーの場合 → ACSMS-MSG-029-003 を表示
