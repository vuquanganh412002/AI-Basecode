### B. 機能詳細


#### 1. 画面の初期化

- **1.1** ログインしているユーザーの役割に基づいてデフォルトのファイル一覧を表示
- **1.2** ファイル一覧の参照範囲（DataScope）：
    ・NICHINO_ADMIN / NICHINO_STAFF
      → 全JAのファイル（`t_file_download` 全件）を参照可能

    ・CHUOKAI（中央会）
      → **同一都道府県の全JA**のファイル + 全JA向けファイル（`ja_id IS NULL`）を参照可能（顧客要件2026-07 / #52132。従来は自JAのみ）
      → 拡大先の県はセッションの `todofuken_code` で決まるため、他県のファイルは参照できない

    ・JA_HONTEN（JA本店）
      → 自JAのファイル + 全JA向けファイル（`ja_id IS NULL`）を参照可能

    ・JA_KANRI_SHITEN（JA管理支店）
      → 自JAのファイル + 全JA向けファイル（`ja_id IS NULL`）を参照可能 ※管理支店単位の絞り込みは行わない

- **1.3** 都道府県プルダウンは ACSMS-API-COMMON-001（`GET /api/v1/todofuken`）から取得：全47都道府県を表示する（役割別の絞り込みは行わない）。FE 側で選択した `todofuken_code` を検索条件として API-022-001 に渡す。
- **1.4** ダウンロード種別プルダウンは `m_code` の `DOWNLOAD_TYPE`（1:口座振替、2:その他、3:増減連絡票、4:増減通知書、5:購読者名簿）から取得する。
- **1.5** 日農ダウンロード許可フラグ（`nichino_download_allowed_flg`）：各帳票出力画面が出力時に設定する（例：増減通知(日農)=TRUE、増減連絡票(販売店)=FALSE、購読者名簿=出力時に選択、口座振替 / 配達手数料=FALSE）。DL制限ロール（role1 / role2 / **role3 中央会**）は `false` のファイルをダウンロード / プレビューできない。**ただし自分が出力したファイルは本フラグを見ない**（顧客要件2026-07 / #52132。本フラグは他組織へ見せてよいかを JA 側が決めるもので、出力者本人を締め出す意図は無い。既定 FALSE のため例外が無いと自分の帳票をDLできない）（サーバ側で403強制）。JA系ロールはこのフラグの影響を受けない。
- **1.6** 画面アクセス / 操作には permission `file.download` が必要。
- **2.0** ファイル検索

#### 2026-01-02 00:00:00. 条件入力：ファイル名（LIKE）、都道府県（ファイルの所有JAの都道府県）、JA（日農ロールのみ）、ダウンロード種別


#### 2026-02-02 00:00:00. 検索ボタン→スコープフィルタリング＋download_datetime DESC


#### 2026-03-02 00:00:00. 検索結果ありの場合　→　データをテーブルに反映し、ページネーション（デフォルト20件/ページ）を表示。検索結果は常に最新順で表示され

  - 検索結果なしの場合　→　ACSMS-MSG-022-001を表示
  - システムエラーの場合　→　ACSMS-MSG-022-004を表示

#### 2026-04-02 00:00:00. 作成者カラムはaccount_nameを表示（`created_by` で m_account からJOIN）。JA名カラムは `ja_id` で m_ja からJOINし ja_code + ja_name を表示。ダウンロード種別カラムは `m_code` DOWNLOAD_TYPE のラベルを表示

  - 日農管理者・日農担当者  → 全ファイルを参照可能
  - 中央会  → **同一都道府県の全JAのファイル** + 全JA向けファイルを参照可能  → 他県のJAのファイルは参照不可（顧客要件2026-07 / #52132）
  - JA本店  → 自JAのファイルのみ参照可能  → 他のJAのファイルは参照不可
  - JA管理支店  → 自JAのファイルのみ参照可能  → JA本店と同様、管理支店単位での絞り込みは行わない

#### 2026-05-02 00:00:00. 権限なしのアカウントの場合　→　ACSMS-MSG-022-006を表示

- **3.0** 検索条件クリア

#### 2026-01-03 00:00:00. 画面上部にある「クリア」ボタンを押下すると、全検索条件（ファイル名＋都道府県＋JA＋ダウンロード種別）＋検索結果一覧をクリア

  - デフォルトのファイル一覧を再表示
- **4.0** ファイルプレビュー

#### 2026-01-04 00:00:00. ファイルのチェックボックスを選択し、「プレビュー」ボタンを押下する時に実行

  - ・ファイル未選択の場合→ACSMS-MSG-022-002を表示
  - ・選択済み→APIプレビュー→モーダル表示（S3 署名付きURL）。画像 / PDF 等プレビュー可能なファイルのみ対象
  - ・無効行（論理削除済み、または日農ロールかつ許可フラグFALSEのファイル）はプレビュー不可
  - ・ファイル不存在→ACSMS-MSG-022-003
- **5.0** ファイルダウンロード

#### 2026-01-05 00:00:00. チェックボックスを選択し→「ダウンロード実行」ボタンを押下する時に実行

  - ・ファイル未選択の場合→ACSMS-MSG-022-002を表示
  - ・選択済み→APIダウンロード→ブラウザで保存ダイアログにてファイル保存
  - ・ダウンロード実行時、ダウンロード履歴の新規登録は行わず、操作ログ（`t_log`、log_type=4）のみ記録する
  - ・無効行（論理削除済み、または日農ロールかつ許可フラグFALSEのファイル）はダウンロード不可（サーバ側で403強制）
  - ・ダウンロード成功の場合　→　ACSMS-MSG-022-005を表示
  - ・ファイル不存在→ACSMS-MSG-022-003
  - ・システムエラーの場合　→　ACSMS-MSG-022-004を表示
- **6.0** 一括ダウンロード（ZIP）

#### 2026-01-05 12:00:00. チェックボックスで1〜50件を選択し→「一括ダウンロード（ZIP）」ボタンを押下する時に実行

  - ・ファイル未選択の場合→ACSMS-MSG-022-002を表示
  - ・選択済み→APIで選択ファイルをZIPにまとめて一括ダウンロード
  - ・無効行は選択不可のためZIP対象に含まれない
  - ・ダウンロード成功の場合　→　ACSMS-MSG-022-005を表示
  - ・システムエラーの場合　→　ACSMS-MSG-022-004を表示
- **7.0** 選択解除＋プレビュークリア

#### 2026-01-06 00:00:00. フッターにある「クリア」ボタンを押下する時、チェックボックスの選択が解除され、プレビューモーダルを閉じ

- **8.0** ページネーション

#### 2026-01-07 00:00:00. 前へ・次へ・ページ番号クリック時、現在の検索条件でページのデータを取得・表示

  - ・デフォルトの表示件数: 20件/ページ。
- **9.0** ファイル選択

#### 2026-01-08 00:00:00. ファイルを選択すると該当行がハイライト表示され、複数ファイル選択可能。無効行は選択不可
