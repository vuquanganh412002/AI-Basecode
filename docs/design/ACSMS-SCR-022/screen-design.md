### A. 機能一覧

| # | 機能 | 項目 | イベント | 説明 |
| --- | --- | --- | --- | --- |
| 1.0 | 画面の初期化 | - | 画面初期表示 | ログインしているユーザーの役割に基づいてデフォルトのファイル一覧を表示 |
| 2.0 | ファイル検索 | 「検索」ボタン | クリック | ファイル名（LIKE）＋都道府県で検索。download_datetime DESCで一覧を表示 |
| 3.0 | 検索条件クリア | 「クリア」ボタン（上） | クリック | 全検索条件と検索結果一覧をクリア。デフォルトのファイル一覧を再表示 |
| 4.0 | ファイルプレビュー | 「プレビュー 」ボタン | クリック | チェックボックスを選択し、該当ファイルの内容をプレビュー |
| 5.0 | ファイルダウンロード | 「ダウンロード実行」ボタン | クリック | チェックボックスを選択し、ファイルのダウンロードを実行 |
| 6.0 | 選択解除＋プレビュークリア | 「クリア」ボタン（下） | クリック | 全チェックボックスを選択解除。プレビューモーダルを閉じ |
| 7.0 | ページネーション | ページネーション | クリック | 次ページのデータ読み込み。検索条件を維持 |
| 8.0 | ファイル選択 | チェックボックス | クリック | ファイルを選択すると該当行がハイライト表示され、複数ファイル選択可能 |

### B. 機能詳細


#### 1. 画面の初期化

- **1.1** ログインしているユーザーの役割に基づいてデフォルトのファイル一覧を表示
- **1.2** ファイル一覧の参照範囲（DataScope）：
    ・NICHINO_ADMIN / NICHINO_STAFF
      → 全ファイル（`t_file_upload` 全件）を参照可能

    ・CHUOKAI（中央会）
      → 自中央会 + 管轄JAのファイル + 全JA向けファイル（`ja_id IS NULL`）を参照可能

    ・JA_HONTEN（JA本店）
      → 自JAのファイル + 全JA向けファイル（`ja_id IS NULL`）を参照可能

    ・JA_KANRI_SHITEN（JA管理支店）
      → 自JAのファイル + 全JA向けファイル（`ja_id IS NULL`）を参照可能 ※管理支店単位の絞り込みは行わない

- **1.3** 都道府県プルダウンは ACSMS-API-COMMON-001（`GET /api/v1/todofuken`）から取得：全47都道府県を表示する（役割別の絞り込みは行わない）。FE 側で選択した `todofuken_code` を検索条件として API-022-001 に渡す。
- **2.0** ファイル検索

#### 2026-01-02 00:00:00. 条件入力：ファイル名（LIKE）、都道府県（ログインユーザのJAの都道府県）


#### 2026-02-02 00:00:00. 検索ボタン→スコープフィルタリング＋download_datetime DESC


#### 2026-03-02 00:00:00. 検索結果ありの場合　→　データをテーブルに反映し、ページネーション（デフォルト20件/ページ）を表示。検索結果は常に最新順で表示され

  - 検索結果なしの場合　→　ACSMS-MSG-022-001を表示
  - システムエラーの場合　→　ACSMS-MSG-022-004を表示

#### 2026-04-02 00:00:00. 作成者カラムはaccount_nameを表示（m_accountからJOIN）

  - 日農管理者・日農担当者  → 全ファイルを参照可能
  - 中央会  → 次のファイルのみ参照可能:  ① 自中央会のファイル  ② 管轄JAのファイル  → 管轄外のJAのファイルは参照不可
  - JA本店  → 自JAのファイルのみ参照可能  → 他のJAのファイルは参照不可
  - JA管理支店  → 自JAのファイルのみ参照可能  → JA本店と同様、管理支店単位での絞り込みは行わない

#### 2026-05-02 00:00:00. 権限なしのアカウントの場合　→　ACSMS-MSG-022-006を表示

- **3.0** 検索条件クリア

#### 2026-01-03 00:00:00. 画面上部にある「クリア」ボタンを押下すると、全検索条件（ファイル名＋都道府県）＋検索結果一覧をクリア

  - デフォルトのファイル一覧を再表示
- **4.0** ファイルプレビュー

#### 2026-01-04 00:00:00. ファイルのチェックボックスを選択し、「プレビュー」ボタンを押下する時に実行

  - ・ファイル未選択の場合→ACSMS-MSG-022-002を表示
  - ・選択済み→APIプレビュー→モーダル表示
  - ・ファイル不存在→ACSMS-MSG-022-003
- **5.0** ファイルダウンロード

#### 2026-01-05 00:00:00. チェックボックスを選択し→「ダウンロード実行」ボタンを押下する時に実行

  - ・ファイル未選択の場合→ACSMS-MSG-022-002を表示
  - ・選択済み→APIダウンロード→ブラウザでファイル保存
  - ・ダウンロード成功の場合　→　ACSMS-MSG-022-005を表示
  - ・ファイル不存在→ACSMS-MSG-022-003
  - ・システムエラーの場合　→　ACSMS-MSG-022-004を表示
- **6.0** 選択解除＋プレビュークリア

#### 2026-01-06 00:00:00. フッターにある「クリア」ボタンを押下する時、チェックボックスの選択が解除され、プレビューモーダルを閉じ

- **7.0** ページネーション

#### 2026-01-07 00:00:00. 前へ・次へ・ページ番号クリック時、現在の検索条件でページのデータを取得・表示

  - ・デフォルトの表示件数: 20件/ページ。
- **8.0** ファイル選択

#### 2026-01-08 00:00:00. ファイルを選択すると該当行がハイライト表示され、複数ファイル選択可能
