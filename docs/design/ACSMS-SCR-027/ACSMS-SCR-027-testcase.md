## システム概要

本システムは、JA向けのクラウド型読者管理システムであり、
購読者情報の管理、購読履歴の管理、口座振替データの管理などの機能を提供する。
主な機能として、購読者情報の登録・更新・検索、
購読内容の変更履歴管理、口座振替データの作成および管理、
ファイルのアップロード・ダウンロード機能、システムのお知らせ管理などを提供する。
また、ユーザーのログイン管理、ログイン履歴の記録、
ユーザー操作ログの記録などのセキュリティ・監査機能をサポートする。

## ACSMS-TC-027-001 — NICHINO_ADMIN によるロール管理画面アクセス可

- 観点ID: VP-A-01
- 種類: Normal (正常)
- 前提条件:
  - ・role: NICHINO_ADMIN
  - ・ログイン済 + MFA認証済

### 手順

ステップ1：
ダッシュボードを開き、サイドバーで「ロール管理」項目を確認

ステップ2：
URL `/roles` を直接入力、または「ロール管理」リンクを押下

ステップ3：
DevTools で GET `/api/v1/roles` を直接呼び出し

ステップ4：
任意のロール（例：role_id=3）の「編集」ボタンを押下

### 期待結果

ステップ1：
サイドバーに「ロール管理」項目が表示されること（NICHINO_ADMIN のみ操作可）

ステップ2：
`/roles` 画面が表示されること、5ロール（NICHINO_ADMIN／NICHINO_STAFF／CHUOKAI／JA_HONTEN／JA_KANRI_SHITEN）が一覧に表示されること

ステップ3：
HTTPステータスコード200が返却されること、レスポンス形式がJSONであること（`data` 配列に5件）

ステップ4：
編集モードへ切り替わること、権限設定パネルが表示されること、ロールコードは無効状態で表示されること

補足：
・FE menu / FE router guard / BE API guard の3層すべてでアクセスを許可すること
・`t_log` には GET 操作の閲覧ログが必要に応じて記録されること
