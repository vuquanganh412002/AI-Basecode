### B. 機能詳細


#### 1. 検索画面表示

- **1.1** 販売店検索画面にアクセスすると、以下のように表示する。本画面はJAの3権限ユーザー（中央会、JA本店、JA管理支店）が操作可能とする。また、日農（担当者）は販売店代行入力から各JAの販売店の新規登録・修正を行うことが出来る。
  - ・空白の検索フォーム
  - ・ログインユーザーのJAに紐づく販売店一覧を表示する。（販売店の一覧を取得する際、論理削除されていないことに加えて、廃店フラグがfalseであることを条件として販売店一覧を取得する。廃店フラグが立っているものは販売店の一覧に表示しないこと）
- **1.2** 画面タイトル：「販売店明細検索」
- **1.3** パンくずリスト：・日農担当者以外の場合：ホーム >  販売店明細検索

#### 2. 販売店検索

- **2.1** 「検索」ボタンをクリックすると、以下の条件で検索を実行する。
  - ・販売店コード：部分一致検索（LIKE '%keyword%'）
  - ・販売店名：部分一致検索（LIKE '%keyword%'）
  - ・電話番号：部分一致検索（LIKE '%keyword%'）
  - ・FAX番号：部分一致検索（LIKE '%keyword%'）
  - ・住所：部分一致検索（LIKE '%keyword%'）
  - ・所長名：部分一致検索（LIKE '%keyword%'）
  - ・廃店フラグ：廃店フラグが立っているものは販売店の一覧に表示しないこと
- **2.2** ログイン中のユーザーのJA（ja_id）で自動フィルタリングする。
- **2.3** 論理削除されたレコードは非表示する（deleted_at IS NULL）
- **2.4** 検索結果がない場合 → ACSMS-MSG-018-001 を表示する。
- **2.5** 権限なしのアカウントの場合 → ACSMS-MSG-018-002 を表示する。
- **2.6** システムエラーの場合 → ACSMS-MSG-018-003 を表示する。

#### 3. 検索条件クリア

- **3.1** 「検索クリア」ボタンをクリックすると、全検索条件をクリアする。
  - ・販売店コード：空欄にする
  - ・販売店名：空欄にする
  - ・電話番号：空欄にする
  - ・FAX番号：空欄にする
  - ・住所：空欄にする
  - ・所長名：空欄にする
- **3.2** 検索結果をリセット、デフォルトの販売店一覧を表示する。
- **4.0** 新規登録
- **4.1** 「販売店情報登録」ボタンをクリックすると、販売店情報登録画面へ遷移する。
- **4.2** 登録画面は空白情報で表示する。

#### 5. 販売店編集

- **5.1** 検索結果一覧から編集対象の販売店を選択すると、販売店登録画面（編集モード）に遷移する。
- **5.2** 販売店IDを登録画面に引き渡し、既存データを取得する。
- **6.0** ページネーション
- **6.1** 検索結果はページネーションされる。
  - ・デフォルト：20件/ページ
  - ・最大：100件/ページ
- **6.2** ページナビゲーション表示：< 1 2 3 ... N >
  - 現在の検索条件を維持したままページを切り替える。
- **7.0** 販売店削除
- **7.1** 操作列の「削除」ボタンをクリックすると、対象販売店が関連テーブルに紐づいているか確認する。
- **7.2** 紐づいている場合 → ACSMS-MSG-018-004 を表示する。削除不可とする。
- **7.3** 紐づいていない場合、確認ダイアログ（ACSMS-MSG-018-005）を表示する。
  - 「はい」をクリックした場合：
  - ・システムは論理削除を実行（deleted_at = NOW()）
  - ・成功メッセージ（ACSMS-MSG-018-006）を表示する。
  - ・検索結果一覧を再度読み込む。
- **7.4** 「いいえ」をクリックした場合 → ダイアログを閉じ、何もしない。
- **7.5** システムエラーの場合 → ACSMS-MSG-018-003 を表示する。
- **8.0** ソート機能
- **8.1** ソート対象カラム:
  - ・販売店コード
  - ・販売店名
- **8.2** カラムヘッダーをクリックした時に実行する。
  - ソート順の切り替えルール:
  - ・初回クリック → 昇順（ASC）
  - ・2回目クリック → 降順（DESC）
  - ・3回目クリック → ソートなし（初期状態）に戻す
- **8.3** 現在のソート状態をカラムヘッダーにアイコンで表示する。
  - ・昇順: ▲アイコン
  - ・降順: ▼アイコン
  - ・ソートなし: アイコン非表示
  - 現在の検索条件を維持したままソートを実行する。
