## システム概要

本システムは、JA向けのクラウド型読者管理システムであり、
購読者情報の管理、購読履歴の管理、口座振替データの管理などの機能を提供する。
主な機能として、購読者情報の登録・更新・検索、
購読内容の変更履歴管理、口座振替データの作成および管理、
ファイルのアップロード・ダウンロード機能、システムのお知らせ管理などを提供する。
また、ユーザーのログイン管理、ログイン履歴の記録、
ユーザー操作ログの記録などのセキュリティ・監査機能をサポートする。

## ACSMS-TC-004-001 — NICHINO_ADMIN によるJAマスタ明細検索画面アクセス（全件閲覧 + 削除可）

- **観点ID**: VP-A-01
- **種類**: Normal (正常)
- **前提条件**:
  - ・role: NICHINO_ADMIN
  - ・ログイン済 + MFA認証済
  - ・事前データ：複数JA（ja-001, ja-002, ja-101 など）が登録済

### 手順

ステップ1：
ダッシュボードを開き、サイドバー「マスタ管理」セクションで「JAマスタ」項目を確認

ステップ2：
「JAマスタ」をクリック → URL `/ja` 画面が開くこと

ステップ3：
一覧テーブルの「操作」列に「削除」リンクが表示されていることを確認

ステップ4：
「新規登録」ボタンが画面右上に表示され、有効状態であることを確認

ステップ5：
DevTools で GET `/api/v1/ja?page=1&per_page=20` を直接呼び出し、レスポンスを確認

### 期待結果

ステップ1：
サイドバーに「JAマスタ」項目が表示される（権限 `ja.view` を保有）

ステップ2：
JAマスタ明細検索画面が正常表示。ヘッダータイトル「JAマスタ明細検索画面」、一覧テーブルに全JAレコードが表示される

ステップ3：
全行の「操作」列に「削除」リンクが表示される（権限 `ja.delete` を保有）

ステップ4：
「新規登録」ボタンが青色（主ボタン）で表示され、クリック可能（権限 `ja.create` を保有）

ステップ5：
HTTP 200、`data` 配列に登録済全JAレコードが含まれる、`meta.total` が DB の登録件数と一致

補足：
・NICHINO_ADMIN は `ja.view` / `ja.create` / `ja.update` / `ja.delete` の全権限を保有
・DataScope なし（`m_account.ja_id IS NULL` のため全JAレコード取得）
・FE menu / FE router guard / BE API guard の3層すべてで許可
