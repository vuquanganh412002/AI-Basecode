| 1 | 初期表示 | 画面全体 | 画面起動 | 検索フォームを空白状態で表示し、デフォルトで購読者一覧を最新順で表示 |
| 2 | 購読者検索 | 検索条件 | 検索ボタン押下 | 入力された条件で購読者情報を検索 |

| 8 | Excel出力 | 検索結果一覧 | 出力ボタン押下 | 検索結果をExcel形式で出力。ダウンロード可能 |
| 9 | 適用日 | 「適用日」ボタン | クリック | 適用日が空欄なら購読者データの最新データフラグが１のものを抽出。適用日が入力されているなら購読者データの変更適用日 <= 画面条件の適用日のものを抽出。購読者データの変更適用日が画面条件の適用日以前のものを抽出 |
| 10 | ソート機能 | ヘッダ | クリック | ID・管理支店・組合員コード・販売店コード・購読開始日・購読中止日によるソート機能 |

### B. 機能詳細


#### 1. 初期表示

- **1.1** 購読者検索画面にアクセスすると、以下のように表示する。
  - ・空白の検索フォーム
  - ・デフォルトの購読者一覧（中央会：自中央会のみ選択可。（管轄JAの読者は見れない）JA本店：自JAのみ選択可。JA管理支店：自管理支店のみ選択可。※電子版クレカ決済者・併読者は編集・削除不可。）
- **1.2** パンくずリスト：ホーム > 購読者明細検索

#### 2. 購読者検索

- **2.1** 検索条件を入力して「検索」ボタンをクリックすると、各項目に対してバリデーションチェックを行い、検索を実行する（論理削除済みレコードは検索結果から除外）。
- **2.2** 検索項目（検索項目のフリーテキスト部分は部分一致とする）
  - ‣常時表示：
  - ・管理支店（kanri_shiten_id）
  - ・支店（shiten_id）(「支店」プルダウンの値一覧が「管理支店」で選択した値に応じて表示される）
  - ・組合員コード（kumiaiin_code）
  - ・氏名（full_name）
  - ・かな氏名（full_name_kana）
  - ・配達先住所（haitatsu）
  - ・配達販売店（hanbaiten_id）
  - ・購読開始日（shoki_dokusya_kaishi_date）（相関チェック：Startdate ≦ Enddate）
  - ・購読中止日（dokusya_chushi_date）（相関チェック：Startdate ≦ Enddate）
  - ・購読種別（dokusya_shubetsu）
  - ・電子承認ステータス（denshi_shonin_status）
  - ‣詳細検索
  - ・引落元口座支店コード（jastem_toriatsukai_tenpo_code）
  - ・引落元口座支店名 (jastem_tenpo_name)
  - ・連絡先１（renrakusaki_1）
  - ・適用日（joho_henko_tekiyo_date）（相関チェック：Startdate ≦ Enddate）
  - ・メールアドレス（email）（形式チャック有り）。メール形式が不正の場合、ACSMS-MSG-014-008を表示する
  - ・請求開始月（seikyu_kaishi_month）
  - ・支払方法 (shiharai_hoho)
  - ・検索結果一覧は常に最新順で表示される。
  - ・検索結果がない場合 → ACSMS-MSG-014-002 を表示する。
  - ・権限なしのアカウントの場合 → ACSMS-MSG-014-004を表示する。
- **2.3** システムエラーの場合 → ACSMS-MSG-014-003を表示する。

#### 3. 検索クリア

- **3.1** 「検索クリア」ボタンをクリックすると、全検索条件をクリアする。
  - ・検索条件を空白にリセットする。
  - ・ページを先頭（1ページ目）に戻る。
- **3.2** デフォルトの購読者一覧を表示する。

#### 4. 新規登録

- **4.1** 「購読者情報登録」ボタンをクリックすると、購読者情報登録画面へ遷移する。
- **4.2** 購読者情報登録画面デフォルトで空白フォームを表示する。

#### 5. 更新（編集モード）

- **5.1** 検索結果一覧から編集したい購読者を選択すると、購読者情報登録画面（編集モード）へ遷移する。
- **5.2** IDを登録画面に渡し、既存データを取得する。

#### 6. 購読者削除

- **6.1** 操作列の「削除」ボタンをクリックすると、対象購読者が関連テーブルに紐づいているか確認する。
- **6.2** 紐づいている場合 → ACSMS-MSG-014-009を表示し、削除不可する。
  - 紐づいていない場合、確認ダイアログ（ACSMS-MSG-014-010）を表示する。
  - 「はい」をクリックした場合：
  - ・システムは論理削除を実行（deleted_at = NOW()）
  - ・削除成功の場合、メッセージ（ACSMS-MSG-014-011）を表示する。
  - ・検索結果一覧を再度読み込む。
  - システムエラーの場合 → ACSMS-MSG-014-003を表示する。

#### 7. ページネーション

- **7.1** 検索結果一覧がページネーションされる。
- **7.2** デフォルト：20件/ページ、最大：100件／ページ
- **7.3** テーブル下部にページナビゲーション（< 1 2 3 ... N >）が表示される）
- **7.4** 現在の検索条件を維持したままページを切り替える。
- **7.5** 検索条件が変わった場合、自動的に1ページ目に戻る。

#### 8. Excel出力機能

- **8.1** 「Excel出力」ボタンを押下する時に実行される。
- **8.2** 検索結果をExcel形式で出力され、ダウンロード可能とする。
- **8.3** Excel出成功の場合　→　ACSMS-MSG-014-005を表示する。
- **8.4** Excel出失敗の場合　→　ACSMS-MSG-014-007を表示する。
- **8.5** 該当データがない場合　→　ACSMS-MSG-014-006を表示する。
- **8.6** 出力件数が30000件超過の場合　→　ACSMS-MSG-014-012を表示し、処理を停止する。

#### 9. 適用日

- **9.1** 適用日が空欄なら購読者データの最新データフラグが１のものを抽出する。
- **9.2** 適用日が入力されているなら購読者データの変更適用日 <= 画面条件の適用日のものを抽出する。
  - 購読者データの変更適用日が画面条件の適用日以前のものを抽出する。

#### 10. ソート機能

- **10.1** ソート対象カラム:
  - ・ID
  - ・管理支店
  - ・組合員コード
  - ・販売店コード
  - ・購読開始日
  - ・購読中止日
- **10.2** カラムヘッダーをクリックした時に実行する。
- **10.3** ソート順の切り替えルール:
  - ・初回クリック → 昇順（ASC）
  - ・2回目クリック → 降順（DESC）
  - ・3回目クリック → ソートなし（初期状態）に戻す
- **10.4** 現在のソート状態をカラムヘッダーにアイコンで表示する。
  - ・昇順: ▲アイコン
  - ・降順: ▼アイコン
  - ・ソートなし: アイコン非表示
- **10.5** 現在の検索条件を維持したままソートを実行する。
