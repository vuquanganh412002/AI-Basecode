### B. 機能詳細


#### 1. 画面初期表示

- **1.1** 購読者販売店一括置換画面にアクセスすると、以下のように表示される。
  - ・空白の検索フォーム（適用日も空白）
  - ・空白の検索結果テーブル（**購読者一覧は自動読み込みしない**・顧客要件 2026-07）
  - ・管理支店ドロップダウンはAPIから取得したデータを表示する。
  - ・配達販売店ドロップダウンはAPIから取得したデータを表示する。
  - ・置換先配達販売店の選択欄は表示しない（検索結果を1件以上選択したときに表示する）。
- **1.2** また、ログインユーザーの権限に応じて、選択可能な範囲を以下のように制限する。
  - ・中央会：自中央会のみ選択可（管轄JAの読者は閲覧不可）
  - ・JA本店：自JAのみ選択可
  - ・JA管理支店：自管理支店のみ選択可

#### 2. 購読者検索

- **2.1** 「検索」ボタンをクリックすると、以下の条件で検索を実行する。
  - ・購読種別（必須・顧客要件 2026-07 改訂）：紙版/電子版 のいずれかを選択。未選択の場合は検索を実行せず「購読種別を選択してください。」を表示する。選択するまで適用日は非活性。**電子版を選択した場合は本画面では対象外のため ACSMS-MSG-015-009（電子版は本画面では対象外です。）をトーストで通知し、検索ボタンを非活性化する（インラインメッセージは表示しない）**（電子版=電子配信で販売店を持たないため一括置換できない・顧客要件 2026-07 改訂）。
  - ・適用日（必須・紙版のみ）：未入力の場合は検索を実行せず ACSMS-MSG-015-004（必須項目です。）を表示する。日付ルールは**紙版=未来日のみ**（当日・過去日不可）。**電子版は対象外**のため適用日入力・検索は行わない。この適用日時点で置換可能な購読者のみを検索結果に表示する（置換可能条件：`購読開始日 <= 適用日` かつ `解約予定日が無い または 解約予定日 > 適用日`）。
  - ・管理支店：選択された管理支店で完全一致検索
  - ・支店：管理支店を正常に選択した後にのみ、「支店」項目が有効化され、検索できるようになる。選択された支店で完全一致検索
  - ・組合員コード：入力された組合員コードで完全一致検索
  - ・かな氏名：名を連結した値で部分一致検索（LIKE）
  - ・配達先住所：住所関連項目を連結した値で部分一致検索（LIKE）
  - ・氏名：姓＋名を連結した値で部分一致検索（LIKE）
  - ・配達販売店：選択された販売店で完全一致検索
  - ・購読開始日：指定された期間で範囲検索。開始日<=終了日の相関チェック
- **2.2** ログイン中のユーザーのJAで自動フィルタリングする。
- **2.3** 登録中の購読者のみ表示し（tetsuzuki_shurui = 1）、論理削除購読者が一覧から除外する。（deleted_at IS NULL）
- **2.4** 検索結果がない場合 → ACSMS-MSG-015-001 を表示する。
- **2.5** 権限なしのアカウントの場合 → ACSMS-MSG-015-002 を表示する。
- **2.6** システムエラーの場合 → ACSMS-MSG-015-003 を表示する。

#### 3. 検索条件クリア

- **3.1** 「検索クリア」ボタンをクリックすると、全検索条件をクリアする。
  - ・管理支店：未選択状態に戻る
  - ・支店：未選択状態に戻る
  - ・組合員コード：空欄にする
  - ・かな氏名：空欄にする
  - ・氏名：空欄にする
  - ・配達先住所：空欄にする
  - ・配達販売店：未選択状態に戻る
  - ・購読開始日 FROM/TO：空欄にする
  - ・適用日：空欄にする
  - ・置換先配達販売店：未選択状態に戻る
- **3.2** 検索結果一覧をクリアし、行選択を解除する。

#### 4. 販売店置換

- **4.1** 「置換処理実行」ボタンをクリックすると、以下のバリデーションを実行する。
  - ・対象ユーザが選択されていますか確認し、選択されていない場合：「置換処理実行」ボタンは無効化される。
  - ・チェックボックスを1つ以上選択すると、「置換先配達販売店」が表示され、必須選択となる（適用日は検索エリアの必須項目で、検索時に既に入力・検証済み。顧客要件 2026-07）。
  - ・置換先配達販売店を選択しているか確認し → 未選択の場合：ACSMS-MSG-015-004を表示する。
  - ・置換先販売店 ≠ 現在の販売店か確認し → 同一の場合：ACSMS-MSG-015-005を表示する。
  - ・購読者が併読者/電子版クレカでないか確認し → ACSMS-MSG-015-006を表示する。
- **4.2** バリデーションOKの場合 → 確認ダイアログを表示：ACSMS-MSG-015-007を表示する。
- **4.3** 「実行」ボタンをクリックした場合：
  - ・購読者販売店一括置換を実行するAPIを呼び出す。
  - ・成功メッセージを表示：ACSMS-MSG-015-008を表示する。
  - ・行選択を解除し、検索結果一覧を再度読み込む。
- **4.4** 「キャンセル」をクリックした場合 → ダイアログを閉じ、何もしない。
  - システムエラーの場合 → ACSMS-MSG-015-003 を表示する。

#### 5. 行選択

- **5.1** 任意の購読者のチェックボックスをチェックする / チェックを解除する。
  - ・ONにする場合、該当の読者が販売店置き換えの対象となる。
  - ・OFFにする場合、該当の読者が販売店置き換えの対象外となる。
- **5.2** 「すべて選択／解除」のチェックボックスをチェックする / チェックを解除
  - ・ONにする場合、一覧内のすべての購読者チェックボックスが自動的にONになる。
  - ・OFFにする場合、一覧内のすべての購読者チェックボックスが自動的にOFFになる。

#### 6. ページネーション

- **6.1** 検索結果はページネーションされる。
  - ・デフォルト：20件/ページ
  - ・最大：100件/ページ

#### 7. 管理支店変更

- **7.1** 管理支店ドロップダウンの値を変更する時
  - ・支店ドロップダウンを未選択状態にリセットする。
  - ・選択された管理支店に紐づく支店一覧をAPIから取得し、支店ドロップダウンに表示する。
- **7.2** 管理支店をクリア（空白に戻す）した場合 → 支店一覧をクリアし、支店ドロップダウンをリセットする。

#### 8. ソート機能

- **8.1** ソート対象カラム：
  - ・管理支店
  - ・支店
  - ・組合員コード
  - ・販売店コード
- **8.5** 現在のソート状態をカラムヘッダーにアイコンで表示する。
  - ・昇順: ▲アイコン
  - ・降順: ▼アイコン
  - ・ソートなし: アイコン非表示
- **8.6** 現在の検索条件を維持したままソートを実行する。
