### B. 機能詳細


#### 1. 画面初期表示

- **1.1** 購読者販売店一括置換画面にアクセスすると、以下のように表示される。
  - ・空白の検索フォーム
  - ・空白の検索結果テーブル
  - ・管理支店ドロップダウンはAPIから取得したデータを表示
  - ・支店ドロップダウンは未選択状態（管理支店を選択するまで無効化）
  - ・配達販売店ドロップダウンはAPIから取得したデータを表示
  - ・置換先配達販売店ドロップダウンは初期非表示（1件以上選択時に表示し、APIから取得したデータを表示）
- **1.2** また、ログインユーザーの権限に応じて、選択可能な範囲を以下のように制限
  - ・中央会：自中央会のみ選択可（管轄JAの読者は閲覧不可）
  - ・JA本店：自JAのみ選択可
  - ・JA管理支店：自管理支店のみ選択可
- **1.3** 各ドロップダウンの読み込みAPI及び権限スコープは以下の通り。BE側で必ずセッションのrole_code / ja_id / kanri_shiten_idを基にスコープを適用する（FEのフィルタは UX のみで、セキュリティ境界ではない）。
  - ・**管理支店ドロップダウン**：`GET /api/v1/kanri-shiten`
    - 中央会：自中央会配下のJAに紐づく管理支店を取得
    - JA本店：自JA配下の管理支店を取得
    - JA管理支店：自管理支店のみ（1件）→ 自動選択 + 無効化（変更不可）
    - 論理削除レコード（deleted_at IS NULL）は除外
  - ・**支店ドロップダウン**：`GET /api/v1/shiten?kanri_shiten_id={selected}`
    - 初期表示時は空。管理支店ドロップダウン変更時のみ読み込み（機能7.1参照）
    - BE側で `kanri_shiten_id` がセッションのスコープ内にあることをアサート（クエリ改ざん防止）
    - 論理削除レコード（deleted_at IS NULL）は除外
  - ・**配達販売店ドロップダウン（検索条件）**：`GET /api/v1/hanbaiten`
    - 中央会：自中央会配下のJAに紐づく販売店を取得
    - JA本店 / JA管理支店：自JAに紐づく販売店を取得（`m_hanbaiten.ja_id` でスコープ）
    - 論理削除レコード（deleted_at IS NULL）は除外
  - ・**置換先配達販売店ドロップダウン**：`GET /api/v1/hanbaiten` （同上APIを再利用）
    - スコープは検索条件側の配達販売店と同一
    - 選択中の購読者が現在所属している販売店をオプションから除外することが望ましい（UX）。ただし最終チェックはBEの「置換先 ≠ 現在の販売店」バリデーション（機能4.1）で担保する
    - 論理削除レコード（deleted_at IS NULL）は除外

#### 2. 購読者検索

- **2.1** 「検索」ボタンをクリックすると、以下の条件で検索を実行
  - ・管理支店：選択された管理支店で完全一致検索
  - ・支店：管理支店を正常に選択した後にのみ、「支店」項目が有効化され、検索できるようになる。選択された支店で完全一致検索
  - ・組合員コード：入力された組合員コードで完全一致検索
  - ・かな氏名：名を連結した値で部分一致検索（LIKE）
  - ・配達先住所：住所関連項目を連結した値で部分一致検索（LIKE）
  - ・氏名：姓＋名を連結した値で部分一致検索（LIKE）
  - ・配達販売店：選択された販売店で完全一致検索
  - ・購読開始日：指定された期間で範囲検索。開始日<=終了日の相関チェック
- **2.2** ログイン中のユーザーのJAで自動フィルタリング
- **2.3** 登録中の購読者のみ表示（tetsuzuki_shurui = 1）、論理削除購読者が一覧から除外（deleted_at IS NULL）
- **2.4** 検索結果がない場合 → ACSMS-MSG-015-001 を表示
- **2.5** 権限なしのアカウントの場合 → ACSMS-MSG-015-002 を表示
- **2.6** システムエラーの場合 → ACSMS-MSG-015-003 を表示

#### 3. 検索条件クリア

- **3.1** 「検索クリア」ボタンをクリックすると、全検索条件をクリア
  - ・管理支店：未選択状態に戻る
  - ・支店：未選択状態に戻る
  - ・組合員コード：空欄にする
  - ・かな氏名：空欄にする
  - ・氏名：空欄にする
  - ・配達先住所：空欄にする
  - ・配達販売店：未選択状態に戻る
  - ・購読開始日 FROM/TO：空欄にする
  - ・適用日：空欄にする
  - ・置換先配達販売店：未選択状態に戻る
- **3.2** 検索結果一覧をクリアし、行選択を解除

#### 4. 販売店置換

- **4.1** 「置換処理実行」ボタンをクリックすると、以下のバリデーションを実行
  - ・対象ユーザが選択されていますか確認し、選択されていない場合：「置換処理実行」ボタンは無効化される。
  - ・チェックボックスを1つ以上選択すると、「置換先配達販売店」と「適用日」が表示され、必須選択となる。同時に「検索」ボタンが無効化される。
  - ・置換先配達販売店を選択しているか確認し → 未選択の場合：ACSMS-MSG-015-004を表示
  - ・適用日を入力しているか確認し → 未入力の場合：ACSMS-MSG-015-004を表示
  - ・置換先販売店 ≠ 現在の販売店か確認し → 同一の場合：ACSMS-MSG-015-005を表示
  - ・購読者が併読者/電子版クレカでないか確認し → ACSMS-MSG-015-006を表示
- **4.2** バリデーションOKの場合 → 確認ダイアログを表示：ACSMS-MSG-015-007を表示
- **4.3** 「実行」ボタンをクリックした場合：
  - ・購読者販売店一括置換を実行するAPIを呼び出す
  - ・成功メッセージを表示：ACSMS-MSG-015-008
  - ・行選択を解除し、検索結果一覧を再読込
- **4.4** 「キャンセル」をクリックした場合 → ダイアログを閉じ、何もしない
  - システムエラーの場合 → ACSMS-MSG-015-003 を表示

#### 5. 行選択

- **5.1** 任意の購読者のチェックボックスをチェックする / チェックを解除
  - ・ONにする場合、該当の読者が販売店置き換えの対象となる
  - ・OFFにする場合、該当の読者が販売店置き換えの対象外となる

- **5.2** 「すべて選択／解除」のチェックボックスをチェックする / チェックを解除
  - ・ONにする場合、一覧内のすべての購読者チェックボックスが自動的にONになる
  - ・OFFにする場合、一覧内のすべての購読者チェックボックスが自動的にOFFになる

#### 6. ページネーション

- **6.1** 検索結果はページネーションされる。
  - ・デフォルト：20件/ページ
  - ・最大：100件/ページ

#### 7. 管理支店変更

- **7.1** 管理支店ドロップダウンの値を変更すると
  - ・支店ドロップダウンを未選択状態にリセット
  - ・選択された管理支店に紐づく支店一覧をAPIから取得し、支店ドロップダウンに表示
- **7.2** 管理支店をクリア（空白に戻す）した場合 → 支店一覧をクリアし、支店ドロップダウンをリセット
- **8.0** ソート機能
- **8.1** 管理支店
  - ・管理支店カラムを昇順／降順でソートする（クリック毎に切替）
  - ・初回クリック時 → 昇順でソート
  - ・同一ヘッダーを再クリック時 → 降順に切替
  - ・他のヘッダークリック時 → 管理支店のソート状態をリセット
- **8.2** 支店

  - ・初回クリック時 → 昇順でソート
  - ・同一ヘッダーを再クリック時 → 降順に切替
  - ・他のヘッダークリック時 → 支店のソート状態をリセット

  - ・初回クリック時 → 昇順でソート
  - ・同一ヘッダーを再クリック時 → 降順に切替
  - ・他のヘッダークリック時 → 組合員コードのソート状態をリセット

  - ・他のヘッダークリック時 → 販売店コードのソート状態をリセット

  - ・昇順: ▲アイコン
  - ・降順: ▼アイコン
