### A. 機能一覧

| # | 機能 | 項目 | イベント | 説明 |
| --- | --- | --- | --- | --- |
| 1 | 画面初期表示 | — | 画面表示 | 出力条件フォームをデフォルト値で表示。プレビューエリアは空 |
| 2 | レポートプレビュー | レポートプレビュー | クリック | 条件をチェックし、データを取得して3つのプレビューテーブルに表示（増部 / 減部 / 住所変更） |
| 3 | 電子帳票作成 | 電子帳票作成 | クリック | 条件をチェックし、電子帳票ファイル（PDF）を生成 |

### B. 機能詳細


#### 1. 画面初期表示

- **1.1** 増減連絡票（販売店）出力画面にアクセスすると、デフォルトで以下のように表示
  - 出力条件フォーム
  - 適用日：未選択
  - 販売店：未選択
  - 管理支店：未選択
  - プレビューエリア：空
- **1.2** 権限チェック：
  - 日農 管理者 / 日農 担当者 → ACSMS-MSG-028-001 を表示。アクセス不可
  - 中央会：自中央会分のみ出力可
  - JA本店：自JAの管理支店分のみ出力可
  - JA管理支店 → 自アカウントのkanri_shiten_idに属するデータのみ出力可
- **1.3** プルダウンリスト：
  - 販売店：m_hanbaitenから取得。電子版ダミー販売店は非表示（廃店（haiten_flg = true）の販売店を除外）
  - 管理支店：m_kanri_shitenから取得。JA支店は自支店のみ表示

#### 2. レポートプレビュー

- **2.1** データ取得ロジック：
  - t_dokusya_rireki テーブルからレコードを抽出
  - 販売店が選択されている場合（全てでない場合）、該当販売店でフィルタリング。未選択の場合、全ての販売店を取得
  - 管理支店が選択されている場合（全てでない場合）、該当管理支店でフィルタリング。未選択の場合、全ての管理支店を取得
  - 適用日：必須項目、入力しない場合：ACSMS-MSG-028-004メッセージを表示。入力した場合：データの変更適用日 =　画面の適用日　かつ　増減報告フラグが1のものを抽出
  - JA管理支店権限の場合 → kanri_shiten_id の条件を追加
- **2.2** グループ化と並び順：
  - 販売店 + 管理支店の組み合わせでグループ化
  - 各組み合わせごとに1枚の帳票を出力
  - 帳票は販売店コードの昇順で作成
- **2.3** 結果表示：
  - 3つのテーブル（増部 / 減部 / 住所変更）をプレビューエリアに表示
  - 各レコードは以下の条件に基づき、増部／減部／住所変更の各テーブルに振り分ける
  - [増部]
  - dokusya_busu > zenkai_dokusya_busu
  - [減部]
  - dokusya_busu < zenkai_dokusya_busu
  - [住所変更]
  - 前回の配達先住所と現在の配達先住所が異なる
  - （前回住所 ≠ 現住所）
  - レポートの表示順序と、項目がない場合の表示方法：①すべての項目を昇順で表示します。②昇順で項目がなくなったら、降順で表示します。③降順で項目がなくなったら、住所が変更された項目を表示します。いずれかのカテゴリに項目が0の場合は、タイトルと空白行を表示します。
  - 帳票ヘッダ：ページ数を表示：Page: 現在ページ/全体数
  - TELとFAXは管理支店の情報を表示
  - 住所変更テーブルは1購読者につき2行（変更前 / 変更後）で表示
- **2.4** 対象データなしの場合 → ACSMS-MSG-028-002 を表示
- **2.5** システムエラーの場合 → ACSMS-MSG-028-003 を表示

#### 3. 電子帳票作成

- **3.1** 「電子帳票作成」ボタンをクリックすると、2.1と同様のデータ取得を実施
- **3.2** データが有効な場合、電子帳票ファイルを生成：（ファイルのテンプレートはまだ共有していただいないため、ご共有いただいた後に更新があれば追記させていただく）
  - 出力形式：PDF
  - 出力後の処理：S3に保存
  - ファイル名：増減連絡票_販売店_{YYYY年MM月DD日}.pdf（適用日に基づく）
- **3.3** 対象データなしの場合 → ファイルは出力しない。ACSMS-MSG-028-002 を表示
- **3.4** システムエラーの場合 → ACSMS-MSG-028-003 を表示
