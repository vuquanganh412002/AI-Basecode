### B. 機能詳細

- **0.0** 初期表示
- **0.1** 画面がデフォルト状態で表示され、取込列パネルは展開された状態で、全てのチェックボックスが選択済みの状態にあり
  - 日農（担当者）は販売店代行入力から各JAの販売店の修正を行うことが出来る。
中央会は自中央会のみ選択可。JA本店とJA管理支店：自JAのみ選択可。

#### 1. Excelファイル選択

- **1.1** 「Excelファイル選択」ボタンをクリック → .xlsx/.xlsフィルター付きダイアログが表示され
- **1.2** ファイル選択後の処理:
  - ・ 先頭シートを取得
  - ・ 1行目 → ファイル内の列ヘッダー一覧
  - ・ 残りの行 → 取込データ
  - ・ 取り込み失敗の場合 → ACSMS-MSG-007-001 を表示
  - ・ 取り込み成功 → プレビューエリアを更新（機能7参照）

#### 2. 取込モード選択

- **2.1** ドロップダウンから選択: 新規登録 / 全項目更新 / 入力箇所のみ更新
- **2.2** デフォルト値: 新規登録

#### 3. テンプレートダウンロード

- **3.1** システムがExcelファイルを生成し、シート名: 「販売店」、1行目に22列を以下の順序通りに設定
  - ・ 販売店コード、販売店名称、販売店名称カナ、インボイス番号、郵便番号、住所、電話番号、
  - ・ FAX番号、所長名、委託区分、配達手数料単価、金融機関コード、金融機関名、
  - ・ 配達手数料支払サイクル、口座支店コード、口座支店名、口座種別、口座番号、
  - ・ 口座名義、手数料区分、手数料、備考、廃店フラグ
- **3.2** ファイル名 ＝ 販売店Excelデータ取込_テンプレート.xlsx でダウンロード

#### 4. 取込列パネルの折りたたみ・展開

- **4.1** パネルが展開状態のとき、クリックすると折りたたまれ
- **4.2** パネルが折りたたみ状態のとき、クリックすると展開され

#### 5. 取込列チェックボックス操作

- **5.1** チェックボックスにチェック入れ／チェック解除により、各チェックボックスの状態を更新、必須列は常にチェック済みで選択不可
- **5.2** 取込データプレビューを再描画（チェック済み列のみ表示）

#### 6. 取込データプレビュー表示

- **6.1** 表示条件: ファイル選択済み かつ データが1行以上存在
- **6.2** 列マッピング: 完全一致優
- **6.3** 非表示条件: ファイル未選択、またはファイルが空の場合

#### 7. 取込処理実行

- **7.1** クライアント側でバリデーションチェックを行い（順序通り）:
  - ・ ファイル未選択 → バリデーションエラー、処理停止
  - ・ データ行数 > 500 → バリデーションエラー、処理停止
- **7.2** 確認ダイアログ ACSMS-MSG-007-002:
  - ・ 「いいえ」→ ダイアログを閉じ、処理しない
  - ・ 「はい」→ データ変換後サーバーへ送信
- **7.3** データ変換・送信：取込み済みのデータを使用（再取込みなし）、チェック有の列のみ、レコードリストに変換、最大500行
- **7.4** 結果処理:
  - ・ 取込み成功の場合（0件エラー）→ 取込件数を表示  → ACSMS-MSG-007-004 を表示
  - ・ エラーありの場合 → 全件ロールバック、「行{N}: {項目名} — {エラー理由}」
  - ・ システムエラー (HTTP 500) → ACSMS-MSG-007-003 を表示
