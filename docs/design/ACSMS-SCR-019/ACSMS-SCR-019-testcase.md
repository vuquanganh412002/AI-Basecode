## システム概要

本システムは、JA向けのクラウド型購読者管理システムであり、
購読者情報の管理、購読履歴の管理、口座振替データの管理などの機能を提供する。
主な機能として、購読者情報の登録・更新・検索、
購読内容の変更履歴管理、口座振替データの作成および管理、
ファイルのアップロード・ダウンロード機能、システムのお知らせ管理などを提供する。
また、ユーザーのログイン管理、ログイン履歴の記録、
ユーザー操作ログの記録などのセキュリティ・監査機能をサポートする。

## ACSMS-TC-019-003 — CHUOKAI による販売店Excelデータ取込 — 自中央会管轄内のみ取込可

- 観点ID: VP-A-02
- 種類: Normal (正常)
- 前提条件:
  - ・role: CHUOKAI（chuokai-001 所属）
  - ・管轄JA: ja-001, ja-002（chuokai-001 配下）
  - ・他中央会管轄JA: ja-099（chuokai-002 配下）
  - ・ログイン済 + MFA認証済

### 手順

ステップ1：
URL `/hanbaiten/import` にアクセス、ja-001 のテンプレートExcelをアップロード、取込モード「新規登録」を選択

ステップ2：
取込開始ボタン押下 → 確認ダイアログ「はい」

ステップ3：
DevTools で POST `/api/v1/hanbaiten/import` に ja-099 配下の hanbaiten_code を含むリクエストボディを送信

### 期待結果

ステップ1：
販売店Excelデータ取込画面が表示されること、プレビューが正常表示されること

ステップ2：
HTTPステータスコード200が返却されること、ja-001 配下にデータが新規登録されること、`m_hanbaiten.ja_id = 1` で保存されること

ステップ3：
ja-099 のデータがCHUOKAI セッションの ja_id ではないため、HTTPステータスコード403が返却されること（`error_code: DATA_SCOPE_VIOLATION`、メッセージ `このデータへのアクセス権限がありません。`）

補足：
・Layer 2 DataScopeにより管轄外JAへの取込は拒否されること
・サーバー側ではセッションの `ja_id` で一律フィルタするため、リクエスト中の他JA `ja_id` 指定は無視またはエラーとなること
