# ■アカウントの考え方について

## ・基本方針

　アカウントは日農が管理する

　１アカウントの同時ログインを可能にする

　日農の担当者が購読者の登録、修正や販売店の置換作業が必要な場合は、JAのアカウントを借りる

　単価マスタ、支店マスタはJA管理とする

## ・日農アカウント

　各種マスタ、アカウントの管理を行う 

　日農はJAの購読者の個人情報を直接参照しない→JAの部数のみわかればよい （増減通知書が見れればよい）

　イレギュラー対応時にJAの販売店情報のみ代行入力できる（販売店代行入力）

　担当者ごとにアカウントを発行する

　日農アカウント権限別に2種類用意する

　①管理者（業務管理部、役員室、企画統括部）

　イレギュラー発生時に直接データを編集する権限を持つ（DBに直接パッチをあてる）

　「使用できる機能」※メニューの分類は画面イメージ_メニュー画面を参照

　・マスタ管理（JAマスタ、管轄支店マスタ）

　・その他機能

　・管理者機能

　・ログ参照（すべて閲覧可能）

　②担当者（各増減担当者に１人１アカウント、県担当用は１支所に１アカウントを作成し共用で使用する）

　「使用できる機能」

　・マスタ管理（JAマスタ、管轄支店マスタ）

　・その他機能

　・販売店代行入力

　・ログ参照（すべて閲覧可能）

## ・中央会アカウント

　中央会…1つのJAとしての機能も持つが、その都道府県のJAを取りまとめる役割も持つ

　中央会自身が部数を扱う場合もある→ただしJAの扱う購読者の個人情報は直接参照しない

　管轄JAの入力のログを確認できる →ログ参照機能が使える

　管轄JAの部数を確認できる →増減通知書が見れればよい

　1中央会に1つのアカウントを発行する（担当者が複数いる場合は担当者別に発行も可）

　中央会の管理支店の部数の管理をする

　管理支店コードのうち（1AA-3300-BBB）

　真ん中の4桁が3300の管理支店のみ選択可能とする（頭3桁で都道府県が決定される）

　「使用できる機能」

　・購読者管理機能（中央会管轄の管理支店のみ選択可能）

　・販売店管理機能

　・データ作成機能

　・レポート作成機能（中央会管轄の管理支店分を出力）

　・マスタ管理の機能（中央会管轄の管理支店のみ選択可能）

　・ファイルダウンロード（中央会管轄の管理支店＋管轄JAのデータを参照可能とする）

　・ログ参照（中央会管轄の管理支店のみ参照可能とする）

## ・JA本店アカウント

　当該JAの管理を行う 

　管轄の管理支店入力のログを確認できる 

　管轄の管理支店の部数を確認できる 

　管轄の管理支店の入力を代行できる 

　1JAに1つのアカウントを発行する（担当者が複数いる場合は担当者別に発行も可）

　「使用できる機能」

　・購読者管理機能（自JAのみ選択可能）

　・販売店管理機能（自JAのみ選択可能）

　・データ作成機能

　・レポート作成機能（自JAの管理支店分を出力）

　・マスタ管理機能

　・その他機能（ファイルダウンロードのみ）

　・ログ参照（自JAのみ選択可能）

## ・JA管理支店アカウント

　当該管理支店の管理を行う 

　1管理支店に1つのアカウントを発行する（担当者が複数いる場合は担当者別に発行も可）

　「使用できる機能」

　・購読者管理機能（自管理支店のみ選択可能）

　・販売店管理機能（自JAのみ選択可能）

　・データ作成機能

　・レポート作成機能（自管理支店分を出力）

　・マスタ管理機能

　・その他機能（ファイルダウンロードのみ）

　・ログ参照（自管理支店のアカウントのみ閲覧可能）

　「所属支店(shiten_id)による追加制限（顧客要件2026-07）」

　　1つの管理支店（例：本店のみ）で複数の支店を運用するJA向けに、JA管理支店アカウントへ任意で「所属支店」を設定できる。所属支店を設定したアカウントは、担当支店単位のさらに狭いスコープで運用される。未設定（NULL）の場合は従来どおり管理支店単位で動作する。

　　・制限①（購読者スコープ）：所属支店を設定したアカウントは、当該支店（t_dokusya.shiten_id）の購読者のみ参照・編集・追加できる。購読者を表示する全画面（購読者明細検索・購読者情報登録・Excel取込・統廃合販売店読者移行 等）に適用。新規/追加時は購読者の管理支店・支店を当該アカウントの所属支店に強制設定する。

　　・制限②（帳票5画面の利用不可）：所属支店を設定したアカウントは、口座振替データ出力(SCR-020)／配達手数料支払情報出力(SCR-021)／購読者名簿(SCR-026)／増減連絡票（販売店）(SCR-028)／増減通知（日本農業新聞）(SCR-029) を使用できない（アクセス時403、メニューは表示のうえ非活性=グレーアウト）。権限（ロール単位）は保持したまま、アカウント属性(shiten_id)ベースの実行時ガードで制御する。

## ・その他

　ファイルアップロード領域は１JAにつき１フォルダとする

　アカウントの権限に電子版の扱いがあるかどうかのフラグを持つ

　電子版の扱いがある＝管理支店がある

　電子版利用がある場合は、Web申込読者承認が使える

　電子版フラグがないアカウントは電子版読者の新規購読登録、解約、承認が出来ない

　アカウントの権限に紙版の扱いがあるかどうかのフラグ（paper_flg）も持つ

　紙版フラグがないアカウントは紙版読者の新規購読登録・編集が出来ない

　購読種別フラグの制御（SCR-011 購読者情報登録画面）：
　・paper_flg=true … 購読種別=紙版(1) の購読者を登録・編集できる
　・denshi_flg=true … 購読種別=電子版(2) の購読者を登録・編集・承認・否認できる
　・両方=true … 上記いずれも可能
　・両方=false … dokusya.create / dokusya.update 権限を持っていても登録・編集は不可。
　　さらに削除・購読者Excelデータ取込・統廃合販売店読者移行も不可（紙版・電子版いずれの
　　取扱い権限も無いため）。該当メニュー（購読者情報登録／購読者Excelデータ取込／
　　統廃合販売店読者移行）は非活性表示、購読者明細検索（参照）のみ可能。
　・削除は対象行の購読種別に従う（紙版→paper_flg、電子版→denshi_flg）。取込・一括置換は
　　購読種別が複数混在しうるため「いずれか一方のフラグ」を要求する。
　・併読(3) は読み取り専用（他システム連携データ）のため本フラグ判定の対象外
　・本制御は role 権限（dokusya.create / dokusya.update）に追加される判定であり、
　　権限とフラグの両方が揃って初めて操作可能。BE が実際の境界
　　（DokusyaService.assertShubetsuFlag が m_account を都度参照）、FE は UX 制御のみ。
　　違反時は HTTP 403 / error_code=SHUBETSU_PERMISSION_DENIED

## 【補足説明】

※1 購読者管理：中央会：自中央会のみ選択可。（管轄JAの読者は見れない）JA本店：自JAのみ選択可。JA管理支店：自管理支店のみ選択可。※電子版クレカ決済者・併読者は編集・削除不可。

※2 販売店管理：日農（担当者）は販売店代行入力から各JAの販売店の新規登録・修正を行うことが出来る。<br>中央会は自中央会のみ選択可。JA本店とJA管理支店：自JAのみ選択可。

※3 レポート作成：増減通知（日本農業新聞）出力：中央会は自中央会分、JA本店は自JAの管理支店分、JA管理支店は自管理支店分のみ出力可。<br>日農はファイルダウンロード機能を通じて増減通知を参照する。

※4 マスタ管理：単価マスタ：中央会は自中央会のみ選択可。JA本店とJA管理支店：自JAのみ選択可。<br>支店マスタ：中央会は自中央会のレコードのみ編集が可能。JA本店とJA管理支店：自JAのレコードのみ編集が可能。日農（管理者）は全JA横断で操作可能（顧客CR 2026-08-24、登録時はJAを選択する代行入力）。<br>※編集可能フィールドは次の項目とする。支店コード、支店名、支店カナ。（購読者情報に使われる支店コード等も同時に更新すること）<br>JAマスタは日農は管理者のみ操作可。中央会は自中央会のレコードのみ一部項目の編集が可能。JA本店は自JAのレコードのみ一部項目の編集が可能。※編集可能フィールドは次の項目とする。郵便番号、住所、電話番号、FAX番号、メールアドレス、担当部署名、担当者名、税区分、備考。<br>管理支店マスタは日農は管理者のみ操作可。中央会は自中央会のレコードのみ一部項目の編集が可能。JA本店は自JAのレコードのみ一部項目の編集が可能。JA管理支店は自JA自管理支店のレコードのみ一部項目の編集が可能。※編集可能フィールドは次の項目とする。郵便番号、住所、電話番号、FAX番号、備考。

※5 ファイルダウンロード・ファイルアップロード：ファイルダウンロード、中央会：自中央会＋管轄JAのデータを参照可。JA本店とJA管理支店：自JAのみ選択可。日農は全データを参照可。ファイルアップロード領域は1JAにつき1フォルダ。<br>※2026-06仕様変更：ファイルアップロードは日農（管理者・担当者）のみ利用可。中央会・JA本店・JA管理支店は不可（migration 1711900900020）。ファイルダウンロードは従来どおり全ロール利用可。

※6 ログ参照：日農：すべてのJAのログを閲覧可。中央会：自中央会のみ参照可。<br>JA本店：管轄の管理支店のみ参照可。JA管理支店：自管理支店のアカウントのみ閲覧可。
