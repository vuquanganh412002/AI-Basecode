# As-Is / To-Be 分析

## ■ システム概要

現在JA向けに提供しているExcel版購読者管理システムを刷新し、クラウド上に次世代の読者管理システムを構築する。
主な目的：①購読者情報の一元管理（紙媒体・電子版の統合）　②FAXによる増減連絡の廃止　③口座振替データ作成業務の効率化
システム化対象外：未収金管理機能

| | 現状（As-Is） | | 理想（To-Be） |
| --- | --- | --- | --- |
| ①<br>購読者管理 | ・紙媒体購読者と電子版購読者の管理が別システム<br>・管理コストの増大、情報の不整合リスクあり | ➡ | ・紙媒体・電子版を同一システムで一元管理<br>・購読者情報の登録・変更・削除を効率化 |
| ②<br>増減情報の連絡 | ・購読者数の増減情報はFAXで連絡<br>・手作業による事務負担が大きい<br>・連絡漏れ・入力ミスのリスクあり | ➡ | ・増減連絡票を電子帳票として作成。<br>・JA担当者のボタン押下で日農へメール自動通知<br>・FAXによる手作業を完全廃止 |
| ③<br>外部システム連携 | ・OAシステムとの連携なし<br>・電子版読者管理システムとの連携なし<br>・手作業でのデータ転記が発生 | ➡ | ・電子版読者管理システムと双方向連携<br>・OAシステムへCSVファイルを出力（将来的な自動連動に備える）<br>・連動エラー時はアラート通知 |
| ④<br>口座振替 | ・口座振替データの作成が手作業 | ➡ | ・口座振替データを全銀フォーマットで出力 |
| ⑤<br>事務作業全般 | ・各種手続きや連絡作業が手動<br>・締め時間の管理が属人的 | ➡ | ・各種手続きの自動化・効率化<br>・締め時間をシステム上に自動表示 |

## ■ 主要課題と対応方針

| # | 課題 | 対応方針 |
| --- | --- | --- |
| 1 | 新聞店統廃合情報の通知・反映方法が未確定 | ファイルアップロード画面から通知。JA担当者へメール通知し、JA担当者自身がマスタへ反映する運用とする |
| 2 | OAシステムとの連携方式 | 自動連動ではなく電子帳票を見てOAシステムに手入力する。OAシステムへ連動するためのCSVファイルをクラウド上に作成（将来的な自動連動に備える） |
| 3 | 電子版購読者の併読管理 | 現状では併読のJA管理は困難と判断。2次開発以降で検討する |
| 4 | 口座振替データのフォーマット統一 | 全銀フォーマットで対応。別フォーマットに関してはエクセルでの出力を可能にすることでJA側の運用で対応する。 |
| 5 | 日割り計算への対応 | システム上は日割り単価を持たない方針。 |
| 6 | JA側の締め時間の意識づけ | システム上に締め時間を表示する（実際の締めとの連動は行わない） |
| 7 | 新システム導入時の初期データ投入 | 業務管理部がJAの初期データ投入をサポートする。<br>購読者情報・販売店情報等、システムの取込機能（購読者Excelデータ取込画面・販売店Excelデータ取込画面）で投入可能なものはシステム経由で行う。<br>システム経由での投入が困難なマスタ情報等は業務管理部や役員室が個別に対応する。 |
