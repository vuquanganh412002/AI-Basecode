# システム連携仕様

## ■ 連携システム概要

| # | 連携先システム | 連携方向 | 連携方式・概要 | 対応フェーズ |
| --- | --- | --- | --- | --- |
| 1 | OAシステム<br>（現行基幹システム） | 本システム → OA | OAシステムへの連携は電子帳票を出力し、手入力する案とシステム上で自動連動する案の２つある。今回は電子帳票を作成し、手入力する案を採用する。ただし、将来的な自動連動への移行余地を残すため、増減連絡電子帳票（PDF）の作成＋CSVファイルのクラウド出力の両方を行う。 | 今回：電子帳票案<br>将来：自動連動案 |
| 2 | 電子版読者管理システム | 双方向（⇔） | 本システム ← 電子版：Web申込読者情報の受信・承認<br>本システム → 電子版：承認済み読者情報の反映・口座振替申込の連携 | 今回対応 |
| 3 | 口座振替システム<br>（全銀フォーマット） | 本システム → 外部 | 口座振替データをテキスト（全銀フォーマット）、またはエクセルデータで出力 | 今回対応 |

## ■ ① OAシステム連携（電子帳票案採用）

| # | 項目 | 区分 | 内容 | 備考 |
| --- | --- | --- | --- | --- |
| 1 | 連携方向 | 本システム → OA | JA担当者がボタン押下により増減連絡電子帳票をクラウド上に作成し、日農増減担当者へメール通知する | FAXによる手作業を廃止 |
| 2 | 出力データ | 増減連絡電子帳票（PDF） | ・新聞店別・JA支店別の扱い部数（増減情報）<br>・電子版読者数<br>・購読開始日基準の増数／購読終了日基準の減数 | 日農増減担当者が閲覧 |
| 3 | 出力データ | OA連動用CSVファイル | 将来的なOAシステム自動連動に備え、CSVファイルをクラウド上に作成・保存する | 現フェーズは自動連動なし<br>※稼働後の実装でも良い、<br>優先度は低い |
| 4 | 連携タイミング | 任意（手動） | JA担当者が任意のタイミングでボタン押下により実行する<br>月の締め時間はシステム上に表示する（実際の締めとの連動なし） | |
| 5 | 通知 | メール通知 | 増減連絡電子帳票作成と同時に日農増減担当者へメール通知を送信する | |
| 6 | 将来対応 | OAシステム自動連動 | 紙版購読者数の増減情報をOAシステムと自動連動させる<br>新聞店の統廃合情報も本システムの新聞店情報に反映する | 2次開発以降で検討 |

## ■ ② 電子版読者管理システム連携

| # | 項目 | 区分 | 内容 | 備考 |
| --- | --- | --- | --- | --- |
| 1 | 連携方向（受信） | 電子版 → 本システム | 電子版読者管理システムからWeb申込されたユーザ情報を本システムへ受信する<br>JA担当者が本システム上で新規登録または承認操作を行う（電子版読者新規登録＋Web申込承認） | |
| 2 | 連携方向（送信） | 本システム → 電子版 | JA担当者が承認した読者情報を電子版読者管理システムへ反映する<br>口座振替で申込されたユーザの承認結果を電子版側へ送信する | |
| 3 | 対象読者 | 電子版読者 | 対象：電子版読者管理システムでJAが選択されている読者 | |
| 4 | データスコープ | 自JA分のみ | JA側システムは当該JA分のデータのみ参照・操作できる<br>他JA分は参照不可 | |
| 5 | エラー処理 | アラート通知 | 電子版読者管理システムとのデータ連動エラーが発生した場合、担当者へアラート通知を行う | |

## ■ ③ 口座振替システム連携

| # | 項目 | 区分 | 内容 | 備考 |
| --- | --- | --- | --- | --- |
| 1 | 連携方向 | 本システム → 外部 | 口座振替データを出力し、口座振替（購読料引き落とし）に使用する | |
| 2 | 出力フォーマット | 全銀フォーマット（標準） | 全銀協標準フォーマット（テキストまたはエクセル）で口座振替データを出力する | |
| 3 | 金額調整 | 手入力による変更 | システム上は日割り単価を持たない方針 | |
| 4 | ログ管理 | 出力履歴の記録 | 出力した口座振替データをログに残し、後から参照できるようにする | ログ参照画面にて対応 |
